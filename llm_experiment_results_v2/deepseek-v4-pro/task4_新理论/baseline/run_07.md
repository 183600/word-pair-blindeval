**理论名称：适应性信息代谢理论（Adaptive Information Metabolism Theory, AIMT）**

这是一个跨学科的思辨性理论草案，用于解释个人、组织和社会在信息过载时代如何维持适应能力。它把“信息”视为一种需要被代谢的资源，而不仅仅是需要被存储或计算的对象。

### 核心命题

所有复杂适应系统——无论是大脑、公司还是社会——的长期存续，不取决于它们获取了多少信息，而取决于它们的**信息代谢效率**：即从外界信息中提取有效结构、更新内部模型、并清除无效信息的能力。

### 四个基本过程

信息代谢分为四个阶段：

1. **信息摄取**：从环境中获取信息。  
2. **信息消化**：过滤、解码、将信息与已有知识结构对接。  
3. **信息同化**：把外部信息转化为内部模型的一部分，提高系统的预测能力。  
4. **信息排泄**：遗忘、压缩或删除过时、冗余、矛盾的信息。

关键点在于：**遗忘不是缺陷，而是代谢的必要环节。** 没有遗忘，系统会被旧信息拖垮。

### 一个简单的形式化

设：

- \( I_{\text{in}} \)：单位时间输入信息量  
- \( C \)：系统内部模型的复杂度，即有效知识结构  
- \( P \)：系统对环境变化的预测准确度  
- \( H \)：未整合的信息熵，即摄入但无法消化的信息量  

定义信息代谢率：

\[
M = \frac{\Delta P}{I_{\text{in}}}
\]

它衡量单位输入信息带来的预测能力提升。健康系统满足：

\[
M > \frac{H}{C}
\]

也就是说，系统将信息转化为结构的能力，必须超过信息堆积带来的混乱。若输入信息过多、过杂，\( H \) 迅速升高，而 \( C \) 增长缓慢，系统就进入“信息代谢综合征”：决策瘫痪、焦虑、内部冲突加剧。

### 主要推论

1. **信息过载的本质不是信息太多，而是代谢率不足。**  
   同样数量的信息，对高代谢系统是营养，对低代谢系统是毒素。

2. **多样性适中原则**：信息多样性过低会导致“认知营养不良”；过高则会超过消化能力，产生“语义肥胖”——知道很多，但理解很少。

3. **遗忘是最被低估的适应机制**。  
   一个系统越能果断地遗忘和压缩旧信息，它就越能快速适应新环境。

4. **组织和社会同样适用**：  
   - 企业信息共享频率存在最优值，过高频率的内部会议会降低创新。  
   - 社交媒体上的信息流如果只追求数量而不提供结构，会降低用户的长期判断力。

### 可检验预测

- 在受控实验中，接受中等多样性信息、并定期进行总结和遗忘训练的人，其决策准确率应高于接受高信息量但无结构整理的人。
- 组织内部信息共享频率与创新绩效之间应呈倒 U 形关系。
- 社会层面，信息代谢率较高的社群在环境突变时恢复速度更快。

### 新意与局限

这个理论的“新”不在于发明了某个孤立概念，而在于把信息处理重新理解为一种**代谢生态过程**，强调遗忘、压缩、转化和排泄的重要性，而不是单纯追求更多信息、更强算力或更大模型。

它的局限是：目前概念如“语义熵”“信息代谢率”还需要更精确的操作化定义和实证测量。它更适合作为一个启发式框架，而非已完成的科学理论。

---

因此，**适应性信息代谢理论**可以概括为一句话：  
**一个系统的强大，不在于它能记住多少，而在于它能从信息中长出什么，并敢于忘记什么。**

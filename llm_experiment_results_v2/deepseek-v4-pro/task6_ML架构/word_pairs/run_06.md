# 双流折叠记忆网络  
**Dual-Stream Folded Memory Network，DSFM-Net**

## 核心思想

当下主流架构里，Transformer 靠注意力捕捉全局关系，Mamba/状态空间模型靠线性递归捕捉长程依赖，但二者往往被当成替代关系。  
DSFM-Net 的出发点来自“双星系统”和“潮汐锁”：**不是让两条路径互相取代，而是让它们像双星一样彼此锁定、周期性交换能量与信息。**

同时，它引入“折叠记忆”概念：  
> 记忆不是被存储在一个平坦的外部记忆中，而是像折纸一样，在训练中不断被折叠、展开、压缩和重构。

## 架构组成

### 1. 双流编码器：潮汐流 + 镜像流

DSFM-Net 每个 block 包含两条并行的信息流：

- **潮汐流（Tidal Stream）**  
  基于状态空间模型或线性递归，负责捕捉长程时序依赖。它像潮水一样有周期性、可预测、低计算成本。

- **镜像流（Mirror Stream）**  
  基于稀疏注意力或图注意力，负责捕捉非序列的全局关系。它像镜子一样瞬间反射远距离依赖。

两条流不是独立运行，而是通过**潮汐锁门控模块**互相调制：

\[
g_t = \sigma(W_h h_t^{\text{潮汐}} + W_m m_t^{\text{镜像}})
\]

\[
\tilde{h}_t = g_t \odot h_t^{\text{潮汐}} + (1 - g_t) \odot m_t^{\text{镜像}}
\]

这样，两个流就像双星围绕质心旋转一样，彼此影响但不失去自己的轨道。

### 2. 折叠记忆模块：琥珀栈

外部记忆以“琥珀化”方式保存，称为**琥珀栈（Amber Stack）**。

每一个重要隐状态会被压缩成低秩张量，并通过可微“折叠算子”折叠多次：

\[
Z^{(l+1)} = \text{Fold}_l(Z^{(l)}) = \text{LowRank}(\text{Reshape}(Z^{(l)})) + \text{Skip}(Z^{(l)})
\]

当需要读取时，通过“展开算子”恢复。折叠次数越多，记忆越抽象、越鲁棒；展开时则逐步恢复细粒度信息。

这类似于折纸：一个复杂形状可以折叠成很小的一块，需要时再展开。

### 3. 共振交互层：波段合成

DSFM-Net 不同层之间不是简单的残差连接，而是采用**共振交互**：

每一层输出会被分解为多个“频率成分”，来自“频谱 虹”和“谐波 雨弦”的意象。

\[
O = \sum_{k=1}^K \alpha_k \cdot \mathcal{F}^{-1}\left( \mathcal{F}(H_k) \odot \mathcal{F}(M_k) \right)
\]

其中 \( \mathcal{F} \) 表示可学习的频域变换。这样，不同频率的信息可以像和弦一样合成，而不是简单相加。

### 4. 压缩宇宙瓶颈

根据“算法信息论 / 压缩宇宙”的灵感，DSFM-Net 在每个大阶段之间插入一个**压缩宇宙瓶颈**：

\[
\mathcal{L}_{\text{compress}} = \lambda \cdot \text{MDL}(Z) + \text{Distortion}(X, \hat{X})
\]

该瓶颈强制中间表示更接近数据的内在最短描述，而不是只关注预测损失。这有助于提升泛化能力和 OOD 鲁棒性。

### 5. 蒸馏潮汐对齐

最后，DSFM-Net 使用**自蒸馏潮汐对齐**进行训练：

- 潮汐流和镜像流分别产生预测；
- 两个预测之间用对比损失对齐；
- 学生模型可以只保留潮汐流，在推理时降低计算量，而不会损失太多镜像流的全局信息。

## 训练目标

总损失为：

\[
\mathcal{L} = \mathcal{L}_{\text{task}} + \alpha \mathcal{L}_{\text{tide-mirror}} + \beta \mathcal{L}_{\text{fold}} + \gamma \mathcal{L}_{\text{compress}}
\]

其中：

- \(\mathcal{L}_{\text{tide-mirror}}\)：双流之间的共振对比损失；
- \(\mathcal{L}_{\text{fold}}\)：折叠与展开的重构损失；
- \(\mathcal{L}_{\text{compress}}\)：压缩宇宙瓶颈的最小描述长度损失。

## 为什么这个架构有潜力？

1. **双重归纳偏置**  
   同时具备线性递归的高效长程建模能力，和注意力/图注意力的全局关系建模能力，而不是二选一。

2. **记忆结构化**  
   折叠记忆模块把“存储”变成“几何变换”，比普通的 KV cache 或 external memory 更具归纳性。

3. **压缩即泛化**  
   压缩宇宙瓶颈把“最短描述长度”显式引入训练，可能缓解过参数化模型对虚假相关的记忆。

4. **推理可降级运行**  
   部署时可以把镜像流蒸馏到潮汐流中，降低显存和延迟，适合边缘设备。

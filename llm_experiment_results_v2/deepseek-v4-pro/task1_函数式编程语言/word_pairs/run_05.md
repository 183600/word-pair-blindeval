---

## 语言名称  
**Dyad / 双生语**，又名 **映潮**。  
座右铭：**“一词为形，一词为影；计算即潮汐。”**

## 核心灵感  
这200组词最强烈的特征是“对偶结构”：  
星尘与织机、潮汐与回声、焰语与静默、光尘与低鸣、静火与回响。  
因此，Dyad 的核心不是单一的值，而是**成对的词**——每个值都有“形”与“影”两面。

---

## 1. 值模型：双生值  
Dyad 中，每个值都由两个词构成：

```
形 : 影
```

例如：

```
5 : 星尘
"你好" : 低鸣
fn x => x : 静火
```

- **形**：实际数据本身。  
- **影**：该值携带的效应、来源、惰性状态、版本或断言信息。  

这使调试、追踪、可逆计算成为语言内建能力。

---

## 2. 类型系统：织机  
类型不是墙，而是“织机”。类型签名本身就像一组词对：

```
星火 : 沙湖 -> 月火
沙舟 : (n : 自然) -> 矢量 n
{ 潮汐: T, 回声: E, ..r }
```

Dyad 支持：

- 依赖类型  
- 行多态记录  
- 对偶类型：`光 / 暗`、`火 / 冰`、`潮 / 沙`  
- 细化类型：`自然 |> 大于 0`

---

## 3. 计算模型：潮汐流  
Dyad 的并发不是线程，而是**潮汐流**。

- `涨潮`：激活计算  
- `退潮`：挂起计算  
- `回声`：传播消息  
- `静潮`：暂停所有副作用  

示例：

```
def 数潮 : 流 自然
数潮 = 潮汐 (0, fn () => 映射 (+1) 数潮)
```

---

## 4. 副作用：代数效应  
副作用被建模为“词对效应”。

例如：

```
effect 焰语 : 文本 -> 单元   -- 输出/日志
effect 静默 : 单元 -> 单元   -- 静默抑制
effect 雾钟 : 时间 -> 单元   -- 定时/延迟
effect 雷纹 : 错误 -> 空     -- 异常
effect 霜纹 : 环境 -> 单元   -- 只读环境
```

处理效应：

```
def 问安 name = do
  焰语 ("你好, " + name)
  pure name

def 安静问安 name =
  with 静默 handle 问安 name
```

## 5. 模块系统：群岛与舟

```

import 雾钟.时间

```

## 7. 语法示例  

```
import 海图.舟

type 流 a = 潮汐 (a, () -> 流 a) | 退潮

def 映射 : (a -> b) -> 流 a -> 流 b
映射 f 流 = match 流
  | 退潮 -> 退潮
  | 潮汐 (x, 尾) -> 潮汐 (f x, fn () => 映射 f (尾 ()))

effect 焰语 : 文本 -> 单元

def 问安 name = do
  焰语 ("你好, " + name)
  pure name

def 静音问安 name =
  with 静默 handle 问安 name

-- 双生值绑定
let 星火 : 光 = 星尘 : 静火

-- 管道与组合
星尘 |> 折光 |> 低鸣
```

## 总结  
Dyad 是一门从“双词结构”中长出来的函数式语言。  
它把计算看作**潮汐**，把类型看作**织机**，把副作用看作**焰语与静默**。  
每个表达式都是一个可追踪、可组合、可反转的**词对**。

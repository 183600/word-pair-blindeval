基于以上词汇——尤其“棱镜、潮汐、星海、光尘、回声、枝桠、星火、雾钟、熔炉、星图”——我设计的新函数式编程语言叫 **Prism**，中文名“棱镜”。

## 1. 设计理念

Prism 的核心隐喻是：

> **数据是星海，函数是棱镜，副作用是潮汐。**

- **星海**：所有数据都像星海中的星尘，不可变、可组合、可观测。
- **棱镜**：函数不是“过程”，而是从一个值到另一个值的折射。
- **潮汐**：副作用像潮汐一样被明确边界包围，不允许静默泛滥。
- **回声**：错误传播像回声一样可追踪、可回放。
- **星火**：并发单元是大量轻量的“星火”。
- **星图**：模块系统叫“星图”，用于组织代码。

## 2. 核心特性

### 2.1 不可变值：光尘

所有值都是不可变“光尘”。没有 `null`，没有隐式类型转换，没有可变变量。

```prism
let x = 42
let xs = [1, 2, 3]
```

### 2.2 函数是透镜

函数用 `lens` 定义，表示从输入到输出的纯映射。

```prism
lens isBright : Star -> Bool =
  \s -> s.brightness > 2.0
```

### 2.3 计算是流

用 `flow` 组织数据变换管道：

```prism
flow stars
  |> filter isBright
  |> map brightnessOf
  |> fold 0.0 (+)
```

### 2.4 副作用被潮汐隔离

有副作用的代码只能写在 `tide` 块里，并显式标注效果类型。

```prism
tide main : () -> () effect {io, console} =
  let data = read "stars.json"
  in emit data
```

### 2.5 错误像回声

错误用 `Echo` 类型传播，可追踪、可组合、可恢复。

```prism
choice FetchError =
  | NotFound Text
  | BadFormat Text
```

### 2.6 并发是星海

使用 `sea` 和 `spark` 进行结构化并发：

```prism
sea {
  for url in urls do
    spark fetch url
  gather
}
```

### 2.7 可逆调试：沙漏

运行时可以记录所有纯函数的输入输出，形成“沙漏日志”，支持倒放执行。

```prism
trace sandglass (main args)
```

## 3. 类型系统

Prism 是静态强类型语言，支持全局类型推断。

- `shape`：记录类型，类似结构体。
- `choice`：和类型，用于表达多种可能。
- `alias`：类型别名。
- `resource`：资源类型，由作用域线性管理。
- `effect`：效果类型，显式追踪副作用。

示例：

```prism
shape Star = {
  name       : Text,
  mass       : Float,
  brightness : Float
}

choice Result a e =
  | Ok a
  | Err e

alias Stars = List Star
```

## 4. 语法速览

```prism
-- 记录
shape Star = {
  name       : Text,
  mass       : Float,
  brightness : Float
}

-- 和类型
choice FetchError =
  | NotFound Text
  | ParseError Text

-- 纯函数
lens brightnessOf : Star -> Float =
  \s -> s.brightness

-- 管道
let totalBrightness : List Star -> Float =
  \stars ->
    flow stars
      |> filter (\s -> s.brightness > 2.0)
      |> map brightnessOf
      |> fold 0.0 (+)

-- 副作用
tide main : () -> () effect {io, console} =
  let raw = read "stars.json"
  in match parse raw with
     | Ok stars -> emit (totalBrightness stars)
     | Err e    -> echo e
```

## 5. 示例：从星海到光尘

一个完整的 Prism 程序：读取星表，过滤亮星，计算总亮度，并并发请求多个数据源。

```prism
chart StarChart where

  shape Star = {
    name       : Text,
    mass       : Float,
    brightness : Float
  }

  choice FetchError =
    | NotFound Text
    | ParseError Text

  lens isBright : Star -> Bool =
    \s -> s.brightness > 2.0

  lens brightnessOf : Star -> Float =
    \s -> s.brightness

  let totalBrightness : List Star -> Float =
    \stars ->
      flow stars
        |> filter isBright
        |> map brightnessOf
        |> fold 0.0 (+)

  tide fetchStars : Text -> Echo FetchError (List Star) effect {io} =
    \path ->
      let raw = read path
      in match parse raw with
         | Ok stars -> Ok stars
         | Err msg  -> Err (ParseError msg)

  tide fetchAll : List Text -> List Star effect {http, time} =
    \urls ->
      sea {
        for url in urls do
          spark fetchStars url
        gather
      }

  tide main : () -> () effect {io, console, http, time} =
    \_ ->
      let urls = ["a.json", "b.json"]
      in match fetchAll urls with
         | Ok stars -> emit (totalBrightness stars)
         | Err e    -> echo e
```

## 6. 与现有语言的差异

- 比 Elm 更强调效果类型，不把副作用全部塞给运行时。
- 比 Roc 更偏向“可逆调试”与“沙漏日志”。
- 比 Haskell 更强调管道和可读性，减少纯符号噪音。
- 比 Rust 更函数式，但保留了线性资源管理的思想。

Prism 不追求海量语法糖，而追求一个高度可预测的计算模型：数据像星海一样不可变，函数像棱镜一样折射输入，副作用像潮汐一样被边界约束，错误像回声一样可追溯。

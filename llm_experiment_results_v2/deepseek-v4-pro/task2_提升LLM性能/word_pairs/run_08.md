从这些词里，我重点提取了：**提示工程、思维树、自洽投票、检索增强、约束解码、模型路由、缓存命中、反思迭代、多路采样、输出格式**等线索。下面给你一套低成本、不需要额外训练、主要靠推理时策略和系统设计来大幅提升现有 LLM 性能的方法。

## 一、提示层优化：成本最低，见效最快

1. **指令精炼**  
   明确角色、任务、输出格式、边界和限制。  
   例：`你是资深数据分析师，请用 JSON 输出结果，不要输出多余解释。`

2. **少样本示例**  
   给 3–5 个高质量示例，示例顺序会影响结果。  
   示例要覆盖边界情况和目标格式。

3. **思维链**  
   复杂推理题加一句：`请一步一步推理，先列出已知条件，再推导结论。`  
   或直接给思维链示例，能显著提升数学、逻辑、规划类任务。

4. **零样本思维链**  
   不加示例，直接让模型：`先分析问题，再给出最终答案。`  
   很多模型对这句话非常敏感。

5. **自我一致性**  
   同一个问题让模型采样 3–5 次，然后投票选多数答案。  
   适合选择题、分类、逻辑推理，能降低单次采样偏差。

6. **思维树/思维图**  
   让模型生成多个推理分支：  
   `请给出三种可能的解决方案，比较它们的优劣，再选择最优解。`

7. **任务分解**  
   复杂任务拆成子任务：  
   `先把问题拆成 3 个子问题，分别回答，最后合并成完整答案。`

8. **上下文压缩**  
   长文档先让模型做摘要或提取关键段，再基于压缩后的上下文回答，避免关键信息被截断或淹没。

## 二、解码与输出控制：让模型“不说废话、不跑偏”

9. **温度调节**  
   需要稳定、可复现时，温度降到 0.1–0.3；需要创意时，温度调到 0.7–1.0。

10. **重复惩罚与频率惩罚**  
    减少模型反复输出同一句话或同一个词，长文生成时效果明显。

11. **约束解码 / 结构化输出**  
    要求输出 JSON、XML、Markdown 或特定模板，可以大幅提升后续解析成功率。  
    例：`只输出合法 JSON，不要输出 Markdown 代码块。`

12. **停止条件**  
    设置停止词，例如 `\n\n###`、`END`，避免生成冗长内容。

13. **长度控制**  
    明确限制：`请用不超过 100 字回答`，或 `请分 3 段，每段不超过 50 字`。

14. **输出格式校验**  
    后处理校验 JSON、SQL、代码等格式，不合格就让模型重新生成，并附上错误信息。

## 三、检索增强：给模型外挂知识，不训练也能变聪明

15. **RAG 基础流程**  
    文档切片 → 嵌入向量 → 相似度检索 → 重排精排 → 注入上下文。

16. **查询改写 / 扩展**  
    把用户问题改写成多个查询，例如：  
    `将这个问题改写成 3 个不同角度的检索查询。`

17. **混合检索**  
    关键词检索 + 向量检索结合，提高召回率。

18. **引用来源**  
    让模型回答时标明引用来源：  
    `请基于给定资料回答，并在每句话后标注来源编号。`

19. **事实核查**  
    对关键事实，让模型先自查：  
    `请检查你的回答是否有事实错误，如有，请修正。`

## 四、系统架构：缓存、路由、降级

20. **语义缓存**  
    相似问题直接返回缓存答案，减少重复推理成本。  
    可以用向量相似度判断两个问题是否足够接近。

21. **提示缓存**  
    相同前缀只处理一次，后续请求复用前缀 KV 缓存，降低延迟和成本。

22. **模型路由**  
    简单任务用小模型，复杂任务用大模型。  
    比如先让模型判断复杂度：`这个任务属于简单、中等还是复杂？`

23. **批处理与异步**  
    非实时任务批量处理，减少请求开销。

24. **超时与重试**  
    设置超时，超时后自动重试或降级到更小模型。

25. **降级策略**  
    大模型不可用时，自动切换备用模型或模板化回答，保证可用性。

## 五、反思与自修正：让模型自己改自己

26. **自我反思**  
    生成答案后，让模型自己检查：  
    `请检查你的回答是否完整、准确、符合格式要求，如有问题请修正。`

27. **自我验证**  
    让模型给出答案的同时写出验证过程：  
    `请给出答案，并说明你为什么认为这个答案正确。`

28. **多角色辩论**  
    模拟两个角色互评：  
    `角色 A 先回答，角色 B 指出问题，角色 A 再修正。`

29. **错误分析**  
    把失败案例的错误模式写回提示词，相当于用提示词做“经验注入”。  
    例：`上次错误是因为忽略了单位换算，这次请先统一单位。`

30. **人类反馈驱动提示迭代**  
    用少量人工标注对比优劣，把偏好写进提示词，而不是训练模型。

## 六、组合使用：效果最明显

单独一个技巧可能只提升几个点，但组合起来会指数级放大。  
一个典型的低成本组合：

> **少样本示例 + 思维链 + 自我一致性 + 结构化输出 + 语义缓存 + 模型路由**

这几乎不需要训练，只需要在提示词、解码参数和系统架构上做调整，就能在复杂任务上实现明显提升。

基于这些灵感词，低成本、不需要额外训练、大幅提升现有 LLM 性能，核心思路是：**不改变模型权重，只改变输入、输出、解码和系统编排**。以下是主要方法：

### 1. 提示工程与上下文学习
- 优化系统提示、角色设定、语气风格。
- 给少样本示例，让模型模仿格式与推理方式。
- 明确输出格式：JSON、表格、列表、标题层级。
- 设置边界、禁忌、检查清单和成功标准。
- 让模型先分析问题，再给出答案。

### 2. 推理策略升级
- 使用思维链、逐步推理、任务分解。
- 复杂问题用“计划—执行—验证”流程。
- 采用自洽采样：多次采样，然后多数投票。
- 使用思维树、图搜索、回溯验证。
- 让模型自我反思、自我批评后再修正。

### 3. 检索增强与外部知识
- 接入向量库、知识图谱、文档检索。
- 将检索到的片段放入上下文，减少幻觉。
- 对长文档先摘要压缩、去重降噪再给模型。
- 常见问题缓存答案，降低重复计算。

### 4. 工具调用与结构化输出
- 让模型调用搜索、计算器、代码执行等工具。
- 约束输出为 JSON/XML/表格，减少格式错误。
- 用正则、语法约束、停止序列控制生成。

### 5. 解码参数调优
- 事实型任务：降低 temperature、top_p，减少随机性。
- 创意型任务：适当调高 temperature，增加多样性。
- 使用束搜索、重复惩罚、长度惩罚。
- 对低置信度输出触发重试或人工兜底。

### 6. 集成与投票
- 同一问题用不同提示模板生成多个答案。
- 对多个答案做一致性、相似度、质量评分。
- 多数投票或加权评分选出最终答案。

### 7. 上下文管理
- 长对话定期摘要压缩，保留关键状态。
- 关键信息前置，避免丢失重要约束。
- 分块处理长文本，再合并结果。

### 8. 自我改进循环
- 模型生成初稿后，再让自己评分、找错、修改。
- 设置验证清单，逐项检查完整性、正确性、逻辑性。
- 多轮迭代直到满足质量指标。

这些方法可以叠加使用。例如：  
**系统提示 + 少样本示例 + 检索知识库 + 思维链 + JSON 输出约束 + 低温解码 + 多次采样投票**，通常能在不训练模型的情况下，显著提升复杂任务的准确率、稳定性和可用性。

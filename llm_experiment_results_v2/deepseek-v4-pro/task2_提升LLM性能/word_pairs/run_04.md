下面回答你的问题：**怎么低成本、不需要额外训练，大幅提升现有 LLM 的性能？**

核心思路是：**不改变模型权重，只优化提示、推理路径、上下文、检索、解码和系统编排。**

## 1. 推理增强：让模型“想清楚再说”

这是提升准确率最明显、成本最低的一类方法。

### 零样本思维链
在问题末尾加一句：

> 请一步一步思考，先给出推理过程，再给出最终结论。

很多任务会立刻提升表现，尤其是数学、逻辑、多步骤决策。

### 少样本思维链
给 2—5 个带完整推理过程的示例。示例要覆盖关键步骤，不要只给最终答案。

### 自一致性
让模型用较高温度生成 5—9 个候选回答，然后投票或综合。  
适合选择题、判断题、分类、推理题。

### 多方案比较
让模型先给出 2—3 个候选方案，再比较优劣，最后选最优。  
这会减少“一条路走到黑”的错误。

## 2. 提示工程：把提示写得更像“工程文档”

### 五要素提示法
每次提示尽量包含：

1. 角色  
2. 任务  
3. 上下文  
4. 输出格式  
5. 禁止事项

示例：

> 你是资深数据分析师。  
> 任务：分析下面销售数据，找出异常点。  
> 上下文：数据如下……  
> 输出格式：用表格列出异常点、可能原因、建议动作。  
> 禁止：不要编造数据；不要输出无关内容。

### 输出格式约束
让模型输出 JSON、Markdown 表格、列表、代码块。  
结构化输出能减少解析错误，也更容易被下游程序使用。

### 任务分解
不要一次让模型完成太复杂的事。  
把大任务拆成流水线：

> 第一步：提取关键信息  
> 第二步：分类问题类型  
> 第三步：生成答案  
> 第四步：检查答案

每一步单独调用模型，整体质量通常更高。

## 3. 检索增强生成：给模型“外部记忆”

不训练模型，但给它查资料的能力。

- 把文档切块，向量化，存入向量库。  
- 用户提问后，检索最相关的 3—10 个片段。  
- 把这些片段放进 prompt，让模型基于证据回答。  
- 要求模型引用来源。

这能显著降低幻觉，提升事实型和知识型任务性能。

## 4. 上下文工程：管理好模型“眼前的信息”

模型对上下文的位置很敏感。

- 重要信息放前面。  
- 指令要明确，不要淹没在长文档里。  
- 对话历史过长时，先做摘要压缩。  
- 删除重复、无关、冲突的信息。  
- 使用标题、编号、分隔符，减少歧义。

## 5. 解码策略优化：用采样换取质量

不训练，只调参数和采样方式。

### 温度
- 事实、推理、数学任务：`temperature = 0.0—0.3`  
- 创意、写作、头脑风暴：`temperature = 0.7—0.9`

### top_p
一般 `0.8—0.95`，配合温度调整。

### best-of-n
生成多个候选，再选最优。  
可以用规则打分、代码验证、人工投票，或者让模型自评。

### 约束解码
限制模型只能输出合法 token，例如 JSON 语法、SQL 语法、指定标签。  
能减少格式错误。

## 6. 系统级编排：多模型、多角色、多工具

### 模型路由
简单任务用便宜小模型，复杂任务用大模型。  
例如：

- 小模型：分类、抽取、改写、意图识别  
- 大模型：复杂推理、长文生成、多步决策

### 多角色协作
用同一个模型或多个模型扮演不同角色：

> 生成者：写出初稿  
> 批评者：找出问题、漏洞、错误  
> 修订者：根据批评修改

循环 1—2 轮，质量提升明显。

### 工具调用
不要让模型硬算。  
让模型调用：

- 计算器  
- 代码解释器  
- 搜索引擎  
- 数据库查询  
- 日历、邮件等外部 API

这相当于给模型“手脚”。

## 7. 最低成本组合建议

如果只做几件事，我推荐这个组合：

1. **零样本思维链**：所有复杂任务都加一句“请一步一步推理”。  
2. **自一致性**：重要任务采样 5 次，投票或综合。  
3. **结构化提示模板**：角色、任务、格式、禁止项写清楚。  
4. **RAG**：事实型、知识型任务接外部检索。  
5. **best-of-n**：生成多个候选再选最优。

这五项基本不需要额外训练，也不需要很高算力，但对很多任务能带来显著提升。

一个通用模板：

```text
你是【领域】专家。
任务：{一句话描述目标}
上下文：
<<<
{相关文档或背景}
>>>
要求：
1. 先分析关键信息和约束；
2. 给出 2—3 个候选方案并比较；
3. 选择最优方案并说明理由；
4. 最终输出 JSON：
{"answer": "...", "reason": "...", "confidence": 0.0}
```

这套方法的核心是：**把模型性能从“训练权重”转移到“提示、检索、推理路径和系统设计”上。**

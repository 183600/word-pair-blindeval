**Idea：`spark` —— 终端创意生成器**

一句话：  
`spark` 是一个把任意两个词强制组合成“独立开发项目灵感”的命令行工具。

核心功能：

- `spark new`：从内置词库中随机抽取一组词，生成一张灵感卡片，包含项目名、一句话简介、3 个核心功能、推荐技术栈、MVP 步骤。
- `spark new --pair "数据流-折纸"`：用户指定两个词，自动生成创意方向。
- `spark add <词1> <词2>`：把新词对加入本地词库。
- `spark list`：查看历史生成记录。
- `spark export --md`：导出 Markdown 灵感笔记。
- 支持 `--seed` 固定随机结果，方便复现。

为什么适合独立开发者：  
项目边界小，单文件即可启动；Python、Node.js 或 Go 都能做；可以自己日常使用，也很适合开源；后续还能接入 LLM API 增强生成质量，但 MVP 完全不需要。

# 「潮汐罗盘：八维十型模型」

它类似九型人格与荣格八维，但用四组核心对立意象构成人格罗盘。

## 一、灵感提取

200 组词中反复出现四组对立/互补意象：

- **根 / 翼**：安全与超越
- **镜 / 窗**：内省与外察
- **火 / 水**：驱动与共情
- **锚 / 帆**：秩序与适应

这四组构成四个主轴，每轴两端各是一个认知功能，共 **八维**。

## 二、八维功能

| 维度 | 象征 | 核心功能 | 阴影 |
|---|---|---|---|
| 根 | Root | 归属、记忆、稳定、延续 | 僵化 |
| 翼 | Wing | 想象、可能、抽象、跨界 | 空想 |
| 镜 | Mirror | 反思、自我觉察、价值判断 | 内耗 |
| 窗 | Window | 观察、现实检验、情境阅读 | 易变 |
| 火 | Fire | 意志、行动、欲望、推动 | 侵略 |
| 水 | Water | 共情、关系、感受、流动 | 淹没 |
| 锚 | Anchor | 秩序、责任、结构、控制 | 控制 |
| 帆 | Sail | 适应、开放、弹性、机会 | 无根 |

每个类型由“主导功能 + 辅助功能”组成，类似九型的核心欲望与恐惧。

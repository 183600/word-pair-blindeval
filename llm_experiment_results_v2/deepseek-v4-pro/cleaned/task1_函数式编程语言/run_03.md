# 星尘（Stardust）

## 设计理念

**星尘**是一门纯函数式、强静态类型、以“时间流”和“代数效应”为核心的编程语言。  
程序被视为无数不可变的“星尘粒子”在“潮汐”般的时间流中组合、过滤、映射与沉淀。

它不是简单地把函数式特性拼在一起，而是尝试回答一个问题：  
如果时间、副作用、模式匹配、缓存、类型推导都像自然意象一样有一等公民地位，语言会是什么样子？

---

## 灵感映射

从前面200组词中抽取了这些核心意象，并映射为语言机制：

| 灵感词 | 语言机制 |
|------|------|
| 星尘 / 潮汐 | 不可变值 / 一等时间流 |
| 熔炉 / 回声 | 代数效应 / 惰性缓存 |
| 棱镜 / 藤蔓 | 模式匹配 / 可组合管道 |
| 罗盘 / 沙漏 | 类型推导 / 资源生命周期 |
| 银钥 / 暗河 | 能力权限 / 隔离异步 |
| 月相 / 磁极 | 类型类 / 型变 |
| 折光 / 倒影 | 视图投影 / 反射 |
| 齿轮 / 孢子 | 递归 / 生成器 |
| 静默 / 低语 | 引用透明 / 显式日志 |
| 海市 / 雾钟 | 延迟计算 / 效应挂起 |

---

## 核心特性

### 1. 一切皆星尘

所有值都是不可变的“星尘粒子”。  
数据类型通过 `type` 定义：

```
type 星尘 a = 粒子 a
             | 暗物质
```

其中 `星尘 a` 是所有可空或可失败值的统一容器。

---

### 2. 潮汐：时间是一等公民

`潮汐` 是语言的异步时间流类型：

```
let 源流 : 潮汐 (星尘 Int) =
  每(200 毫秒) 产生 (1..10)
```

时间流可以映射、过滤、合并、分区：

```
let 慢流 =
  源流
  |> 潮汐节流 300 毫秒
  |> 潮汐映射 (x -> x * 2)
```

---

### 3. 熔炉：代数效应系统

副作用不直接发生，而是通过 `熔炉` 声明并解耦：

```
effect 熔炉 {
  燃烧 : Int -> Int
  淬火 : Int -> Int
}
```

调用方只描述需要什么效应：

```
let 加工 x = 执行 {
  燃烧 x
}
```

处理方决定如何满足：

```
处理 加工 用 {
  燃烧 k x -> k (x + 1)
  淬火 k x -> k (x - 1)
}
```

---

### 4. 棱镜：模式匹配与投影

`棱镜` 提供穷尽匹配，并可从复杂结构中“折光”出需要的部分：

```
let 观察 = 用棱镜 {
  粒子 n -> "得到 " + n
  暗物质 -> "空"
}
```

记录类型也可以通过棱镜访问：

```
type 用户 = { 名字: String, 年龄: Int }

let 名字棱镜 = 棱镜 用户.名字
```

---

### 5. 回声：惰性缓存与引用透明

纯函数默认透明，但可用 `回声` 强调惰性缓存：

```
let 慢计算 = 回声 (x -> {
  重计算 x
})
```

相同输入只会计算一次，结果被缓存。

---

### 6. 藤蔓：可组合管道

`藤蔓` 是语言内置的组合器，让函数像藤蔓一样生长、串联：

```
let 管道 = 藤蔓 [
  观察,
  用回声 缓存,
  过滤 (x -> x > 5),
  映射 (x -> x + 1)
]
```

---

### 7. 罗盘：全局类型推导

无需手动标注大多数类型，编译器沿着“罗盘”自动推导：

```
let 值 = 熔炼 1
let 结果 = 管道(源流)
```

编译器能推导出 `结果 : 潮汐 (星尘 Int)`。

---

### 8. 沙漏与银钥：资源与安全

`沙漏` 管理文件、连接等线性资源：

```
with 沙漏 {
  打开 文件 "data.txt" 作为 输入:
    读取 输入
}
```

`银钥` 控制效应权限，只有持有对应钥匙的代码才能执行“暗河”类异步副作用。

---

## 完整代码示例

```
-- 语言：星尘（Stardust）
-- 灵感词：星尘、潮汐、熔炉、回声、棱镜、藤蔓、罗盘、沙漏、银钥

module 星光处理

import 星尘/核心
import 星尘/潮汐
import 星尘/熔炉
import 星尘/棱镜
import 星尘/藤蔓

type 星尘 a = 粒子 a
             | 暗物质

effect 熔炉 {
  燃烧 : Int -> Int
  淬火 : Int -> Int
}

let 源流 : 潮汐 (星尘 Int) =
  每(1 秒) 熔炼 (1..8)

let 管道 = 藤蔓 [
  用棱镜 {
    粒子 n -> 燃烧 n
    暗物质 -> 0
  },
  用回声 缓存,
  过滤 (x -> x > 2),
  映射 (x -> x * 10)
]

let 主 = 处理 管道(源流) 用 {
  燃烧 k x -> k (x + 5),
  淬火 k x -> k (x - 3)
}

-- 输出为潮汐流：
-- 每秒释放一个经过熔炉加工、棱镜解构、回声缓存后的星尘值
```

---

## 总结

这门语言叫 **星尘**。  
它把“时间流、代数效应、惰性缓存、模式匹配、类型推导、资源安全”分别对应为前面词库中的潮汐、熔炉、回声、棱镜、罗盘、沙漏等意象。

它不是简单的语法糖拼装，而是试图让不可变数据像星尘一样流动，让副作用像熔炉一样被锻造，让程序像藤蔓一样生长。

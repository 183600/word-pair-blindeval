## 语言名称：**Mira**  
中文名：**微光**  
取自第 1 组“晨雾 微光”、第 3 组“星尘 编译”和第 200 组“晨星 启程”。  
Mira 的核心理念是：**程序如星尘，类型如脉络，计算如潮汐，副作用如涟漪。**

---

## 一、设计哲学

Mira 是一门强类型、纯函数优先、代数效应驱动的函数式编程语言。它强调：

- **不可变数据**：所有值默认不可变，如第 77 组“沙粒 不可变”。
- **显式副作用**：副作用必须通过效应系统声明，如第 33 组“潮痕 副作用”。
- **类型即脉络**：类型系统像脉络一样连接程序，如第 5 组“脉络 类型”。
- **并发如潮汐**：并发模型基于潮汐调度，如第 4 组“潮汐 同步”。
- **模块如根须**：模块依赖如根须般清晰，如第 15 组“根须 依赖”。

## 二、核心特性

### 1. 类型系统：脉络类型

类型系统支持：

- 行多态记录与变体  
- 轻量依赖类型  
- 类型类  
- 细化类型  
- 编译期类型推导，如第 31 组“灵光 推导”

类型声明示例：

```mira
type Shape =
  | Circle { radius: Float }
  | Rect { width: Float, height: Float }

type alias Name = String
type alias Age = Int

type Result e a =
  | Ok a
  | Err e
```

类型像“脉络”一样可追踪，每个类型错误都带有路径信息。

### 2. 纯函数与效应系统

Mira 区分纯函数与有副作用函数。副作用通过代数效应声明和处理。

效应声明来自第 33 组“潮痕 副作用”与第 117 组“雷云 异步异常”：

```mira
effect Log = {
  emit(msg: String) -> ()
}

effect Fetch = {
  request(url: String) -> Response
}
```

使用效应时，函数类型中必须显式标注：

```mira
let logAndCompute : Int -> Int ! Log
logAndCompute x =
  Log.emit("开始计算")
  let y = x * 2
  Log.emit("计算结束")
  y
```

效应处理：

```mira
let main : () -> IO ()
main _ =
  handle logAndCompute 21 with
    | Log.emit msg => IO.println(msg); resume ()
```

### 3. 不可变数据与结构共享

所有数据结构不可变，默认使用结构共享。  
灵感来自第 77 组“沙粒 不可变”、第 94 组“磐石 不变”。

```mira
let xs = [1, 2, 3]
let ys = xs ++ [4]   // 生成新列表，不修改 xs
let zs = { xs | head = 0 }  // 记录更新，产生新记录
```

### 4. 惰性与显式严格

灵感来自第 17 组“沙漏 惰性”和第 71 组“磷火 惰性求值”。

Mira 支持惰性数据结构，但默认求值是严格求值。惰性通过 `lazy` 显式声明：

```mira
let stream = lazy [1..]  // 无限惰性序列
let firstTen = stream |> take 10
```

### 5. 并发模型：潮汐调度

灵感来自第 4 组“潮汐 同步”、第 30 组“蜂群 并行”、第 107 组“潮涌 并发原语”。

Mira 的并发模型叫 **潮汐调度**：

- 任务如潮水一样周期性推进  
- 使用纤程，如第 126 组“蚕丝 纤程”  
- 并发原语包括 `tide`、`parMap`、`chan`、`actor`

```mira
let fetchAll : List String -> (List Response) ! IO

```

### 代数数据类型与泛型

```mira
type Tree a =
  | Leaf
  | Node { value: a, left: Tree a, right: Tree a }

let insert : Ord a => a -> Tree a -> Tree a
```

## 五、示例程序：恒星计算器

```mira
module Stardust

import Mira.Prelude

type Planet =
  { name: String
  , mass: Float
  , radius: Float
  }

let gravity : Planet -> Float
gravity p =
  let g = 6.67430e-11
  g * p.mass / (p.radius ** 2.0)

effect Log = {
  emit(msg: String) -> ()
}

let showGravity : Planet -> Float ! Log
showGravity p =
  let g = gravity p
  Log.emit("计算 " ++ p.name ++ " 的重力")
  g

let main : () -> IO ()
main _ =
  let earth = { name = "地球", mass = 5.972e24, radius = 6.371e6 }
  handle showGravity earth with
    | Log.emit msg => IO.println("[日志] " ++ msg); resume ()
```

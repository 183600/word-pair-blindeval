## 语言设计：**星尘回响 Stardust Echo**

从第 1 组“星尘/回响”和第 200 组“星尘/起源”获得命名灵感。  
**星尘回响**是一门以“代数效应 + 惰性流 + 强静态类型”为核心的纯函数式编程语言。

### 设计哲学

- 一切计算都是**回响**：纯函数可被自动记忆化，像回声一样复用。
- 类型如**星尘**：类型宇宙分层但可组合，支持高阶类型与类型族。
- 副作用如**天气**：不直接发生，而是作为可处理的效应出现。
- 数据如**花岗**：默认不可变，变更只生成新的持久化结构。
- 模块边界如**海雾**：默认隐藏实现，只暴露明确接口。

### 灵感映射示例

| 词对 | 语言特性 |
|---|---|
| 棱镜/模式 | `prism` 模式匹配 |
| 藤蔓/延续 | `vine` 递归与延续 |
| 磁暴/并发 | `storm` 并发效应 |
| 潮汐/编译 | 编译分阶段：涨潮、平潮、退潮 |
| 沙漏/求值 | 线性资源与时间约束 |
| 孢子/泛型 | `spore` 泛型自动派生 |
| 结晶/不变量 | `crystal` 不变量契约 |
| 光斑/透镜 | `lens` 光学组合子 |
| 年轮/缓存 | 自动版本化缓存 |
| 菌丝/网络 | 分布式拓扑 |
| 沙暴/沙箱 | 能力安全沙箱 |
| 鲸落/资源 | 线性资源回收 |
| 岩画/文档 | 文档即代码 |
| 霜降/不可变 | 默认不可变数据 |

### 语法示例

```haskell
-- 代数数据类型
data Shape = Circle Float | Rect Float Float

-- 模式匹配
area : Shape -> Float
area s = match s
  | Circle r => pi * r * r
  | Rect w h => w * h

-- 代数效应：定义一组可处理副作用
effect Storm {
  emit : Text -> Unit
  sleep : Duration -> Unit
}

program : () -> Storm () Unit
program () = do
  emit "start"
  sleep 120ms
  emit "end"

main : Unit
main =
  handle program ()
  with
    | emit msg => log msg; resume ()
    | sleep d  => wait d;  resume ()

-- 惰性流
type NatStream = Tide Int

nats : NatStream
nats = unfold 0 (\n => Just (n, n + 1))

first10 : List Int
first10 = take 10 nats |> toList

-- 类型类
grain Additive a where
  zero : a
  combine : a -> a -> a

instance Additive Int where
  zero = 0
  combine = (+)
```

### 核心特性

1. **纯函数默认**  
   函数默认无副作用，副作用必须通过 `effect` 显式声明。

2. **强静态类型**  
   类型系统支持 Hindley-Milner 推断、高阶类型、类型族、行多态。

3. **代数效应**  
   副作用被建模为可组合的效应，可被 `handle` 捕获、改写或继续。

4. **惰性流 `Tide`**  
   默认求值严格，但 `Tide` 类型提供可组合的惰性流。

5. **结构化并发 `Storm`**  
   并发是一种效应，支持 `flock` 并发原语、`whale song` 分布式消息。

6. **能力沙箱 `Sandstorm`**  
   所有不纯操作都需要能力授权，形成安全边界。

7. **回响缓存 `Echo`**  
   标记为 `echo` 的纯函数自动记忆化，避免重复计算。

8. **模块边界 `Fog`**  
   模块默认不透明，仅暴露 `exposed` 声明。

9. **文档即代码 `Petroglyph`**  
   文档嵌入类型与测试，保持同步。

10. **编译期宏 `Stardust`**  
    通过 `stardust macro` 在编译期生成和变换代码。

### 总结

**星尘回响**试图把自然意象、函数式严谨性和效应系统融合在一起：类型像星尘一样组合，计算像回响一样可复用，副作用像天气一样可以被处理。它适合数据流、分布式系统、可验证计算和高可靠性工具链。

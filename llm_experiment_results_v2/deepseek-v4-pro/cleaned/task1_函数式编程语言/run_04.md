## 语言名称：织星 / Aster

一种全新的纯函数式编程语言，默认惰性、显式效应、结构化并发、精化类型、一级模式匹配。

文件后缀：`.ast`

---

## 1. 核心设计原则

| 关键词 | 语言特性 |
|---|---|
| 星尘 | 默认惰性求值，延迟计算像星尘一样悬浮 |
| 琥珀 | 所有值默认不可变，使用持久数据结构 |
| 河流 | 数据流作为一等公民，管道是主要组合方式 |
| 回声 | 模式匹配是唯一控制流核心 |
| 彩虹 | 副作用必须显式声明为效应 |
| 光与影 | 线性类型管理资源，纯函数与副作用函数严格区分 |
| 织机 | 并发通过编织多个丝绸线程实现 |
| 蜂巢 | 数据并行是结构化并发的一部分 |
| 钻石 | 精化类型可以表达不变量 |
| 罗盘 | 编译器提供类型导向的代码合成 |

## 2. 语法速览

```aster
module Main

import Std.Stream
import Std.Hive
import Std.Console

// 值定义：不可变持久值
val answer = 42

// 函数：柯里化、部分应用
fn add a b = a + b
val inc = add 1

// 代数数据类型
type Tree a =
  | Empty
  | Leaf a
  | Branch (Tree a) (Tree a)

// 模式匹配
fn sumTree t =
  match t with
  | Empty -> 0
  | Leaf x -> x
  | Branch l r -> sumTree l + sumTree r
  end

// 管道：雨滴式流组合
val result =
  [1, 2, 3, 4]
  |> map inc
  |> filter (fn x -> x > 2)
  |> reduce (+) 0

// 惰性无限序列
val naturals = seed 0 (fn n -> n + 1)
val firstTenSquares =
  naturals
  |> map (fn n -> n * n)
  |> take 10
  |> toList
```

## 3. 类型系统

Aster 的类型系统分为五层：

1. **基础层**：静态强类型，支持泛型与高级类型推断。  
2. **代数层**：归纳类型、和类型、积类型。  
3. **精化层**：用谓词精化类型。  
4. **线性层**：线性类型和借用语义管理资源。  
5. **效应层**：效应行类型分离纯函数和副作用。

### 3.1 精化类型

```aster
type Email = String where s -> s.contains '@'
type Port  = Int where n -> 0 <= n && n <= 65535

fn send target:Email content:String = ...
```

### 3.2 线性类型

```aster
lin val handle = open "file.txt"   // 必须精确使用一次
lin val result = read handle
lin val () = close handle           // 关闭后不可再使用
```

### 3.3 效应系统

```aster
effect Console where
  log : String -> ()

effect State s where
  get : () -> s
  put : s -> ()

fn greet name : { Console } () =
  Console.log ("Hi " ++ name)

fn counter : { State Int + Console } () =
  let n = State.get () in
  State.put (n + 1)
```

只使用 `{ Console }` 的函数不能被调用 `{ State Int }` 的上下文，除非显式处理效应。

## 4. 求值模型

- 默认惰性求值，使用图归约。  
- 尾调用自动优化。  
- 持久数据结构采用哈希数组映射树。  
- 纯函数引用透明，可安全记忆化。  
- 显式 `memo` 关键字可缓存惰性值。

```aster
val expensive = memo (fn x -> compute x)
```

---

## 5. 并发模型

Aster 的并发不是简单的线程库，而是语言级结构：

### 5.1 蜂巢数据并行

```aster
val huge = [1..1000000]

val processed =
  huge
  |> hive (fn x -> x * x + 1)
  |> reduce (+) 0
```

### 5.2 织机结构化并发

```aster
val (a, b) =
  weave
    |> silk (fn -> workerA)
    |> silk (fn -> workerB)
    |> join
```

### 5.3 协议会话

```aster
protocol Echo where
  send : Int -> ()
  recv : () -> Int

val echo = spawn Echo (fn (send, recv) ->
  loop (fn n -> send (recv () + 1))
)
```

---

## 6. 模式匹配与错误处理

模式匹配不只是一个表达式，而是一等能力。

```aster
fn safeDivide x y =
  match y with
  | 0 -> Error "division by zero"
  | _ -> Ok (x / y)
  end
```

异常不是隐式出现，而是效应：

```aster
effect Exception e where
  raise : e -> a
  catch : (() -> a) -> (e -> a) -> a
```

---

## 7. 模块系统

模块是“岛屿”，互相隔离，通过“桥梁”导入。

```aster
module Image.Filter

import Std.Color
import Std.Matrix

fn blur img radius =
  img
  |> Matrix.convolve (gaussian radius)
  |> Color.normalize
```

---

## 8. 元编程与反射

Aster 支持受控反射和语法扩展。

```aster
val ast = reflect (fn x -> x + 1)
val src = quote (map inc [1,2,3])
```

宏系统使用 `quote` / `unquote`，在编译期生成代码。

## 9. 示例程序：词频统计

```aster
module WordCount

import Std.Stream
import Std.File
import Std.Console

effect FileIO where
  read : String -> String
  write : String -> String -> ()

fn normalize word = word.lower()

fn main : { FileIO + Exception } () =
  "input.txt"
  |> FileIO.read
  |> split ' '
  |> filter (fn w -> w != "")
  |> map normalize
  |> frequencies
  |> top 10
  |> renderTable
  |> FileIO.write "output.txt"
```

## 10. 总结

织星 / Aster 的设计核心不是语法糖堆叠，而是：

- 惰性像星尘一样弥漫，但效应必须如光影一样清晰。  
- 数据像琥珀一样不可变，像河流一样流动。  
- 并发像织机一样有结构，像蜂巢一样可并行。  
- 类型像山脉和蓝图一样提供约束，像罗盘一样引导程序合成。

这是一种从自然、时间、空间与工艺隐喻中生长出来的全新函数式语言。

```

## 9. 示例程序：词频统计

```aster
module WordCount

import Std.Stream
import Std.File
import Std.Console

effect FileIO where
  read : String -> String
  write : String -> String -> ()

fn normalize word = word.lower()

fn main : { FileIO + Exception } () =
  "input.txt"
  |> FileIO.read
  |> split ' '
  |> filter (fn w -> w != "")
  |> map normalize
  |> frequencies
  |> top 10
  |> renderTable
  |> FileIO.write "output.txt"

## 10. 总结

织星 / Aster 的设计核心不是语法糖堆叠，而是：

- 惰性像星尘一样弥漫，但效应必须如光影一样清晰。  
- 数据像琥珀一样不可变，像河流一样流动。  
- 并发像织机一样有结构，像蜂巢一样可并行。  
- 类型像山脉和蓝图一样提供约束，像罗盘一样引导程序合成。

这是一种从自然、时间、空间与工艺隐喻中生长出来的全新函数式语言。

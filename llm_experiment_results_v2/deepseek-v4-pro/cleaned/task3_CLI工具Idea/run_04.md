**工具名称**：RelCLI / AutoRelease  
**核心功能**：自动从 Git 提交历史生成语义化版本号和 CHANGELOG，并发布到 GitHub/GitLab Releases。  
**目标用户**：独立开发者、小型团队。

**MVP 功能**：  
- `relcli init`：初始化配置，选择发布分支、版本前缀、模板风格。  
- `relcli preview`：扫描 git log，按约定式提交解析 feat/fix/breaking，预览生成的 CHANGELOG 和版本号。  
- `relcli release`：生成 CHANGELOG.md、打 tag、推送代码并创建 Release。  
- 支持 GitHub、GitLab、Gitee 等平台适配。

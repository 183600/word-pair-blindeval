# 新函数式编程语言：潮织（Tideweave）

一句话定义：  
**潮织是一种纯函数式、静态类型、以“效应光谱、潮汐并发、织纹模块、线性契约”为核心的实验性函数式编程语言。**

它从词对中的这些意象获得主要灵感：

- **光·影、折·射、光·谱、投·影** → 把副作用建模为“效应光谱”，用处理器进行折射与消解。
- **潮·汐、流·水、管·道、队·列、协·程** → 采用结构化并发模型“tide”，像潮汐一样汇聚、取消、回流结果。
- **线·结、织·梭、布·纹、针·脚** → 模块、类型和模式匹配采用“织纹”组合方式。
- **种·芽、根·须、树·根、递·归** → 以代数数据类型和递归折叠为基本计算单位。
- **锁·钥、契·约、不·变、线·性** → 用线性能力与契约约束资源使用。
- **晶·格、液·晶、凝·胶、沉·淀** → 类型推导中引入“晶格约束”和效果行统一。

---

## 1. 核心设计

### 1.1 纯函数式，默认不可变
所有值默认不可变；更新通过“折面透镜”生成新值，而不是修改旧值。

```tideweave
type Person = {
  name: Text,
  age: Int,
  city: Text
}

fn birthday(p: Person) -> Person =
  p { age = p.age + 1 }
```

### 1.2 效应光谱
函数类型可以携带效应行：

```tideweave
fn read_config(path: Path) -> Config !{fs, log}
```

`!{fs, log}` 表示该函数可能产生文件系统与日志效应。纯函数不写效应行。  
效应处理器称为“棱镜”，可把带效应的计算折射成纯值或另一种效应：

```tideweave
fn main() -> () !{io} =
  io.println("你好，潮织")
```

### 1.3 潮汐并发
并发使用 `tide` 块。它像结构化并发的织机：分叉任务、等待汇聚、任一失败则取消其余任务，并保持结果顺序稳定。

```tideweave
fn fetch_all(urls: List[Url]) -> List[Text] !{net, tide} =
  tide for url in urls yield {
    net.get(url)
  }
```

`fetch_all` 的返回结果顺序与 `urls` 一致；底层可并行执行，但语义是确定性的。

### 1.4 线性契约
资源类型使用线性或仿射约束，例如打开的文件必须被关闭：

```tideweave
fn with_file(path: Path, use: fn(@File) -> A) -> A !{fs} =
  let f = fs.open(path) in
  tideweave finally fs.close(f) {
    use(f)
  }
```

`@File` 表示拥有型线性资源；`&File` 表示只读借用。

## 2. 类型系统

潮织采用：

- Hindley–Milner 类型推导；
- 行多态记录；
- 代数数据类型；
- 效应行；
- 线性/仿射资源；
- 可选显式类型标注；
- 类型类，称为“晶格类”。

示例：

```tideweave
type Tree[a] =
  | Leaf(a)
  | Node(Tree[a], Tree[a])

fn sum(t: Tree[Int]) -> Int =
  match t {
    Leaf(x) => x
    Node(l, r) => sum(l) + sum(r)
  }
```

行多态记录：

```tideweave
fn name_of(p: {name: Text, ..r}) -> Text =
  p.name
```

效应行可组合：

```tideweave
fn noisy_add(x: Int, y: Int) -> Int !{rand, log} =
  log.info("adding {x} and {y}")
  x + y + rand.int(0, 10)
```

效应处理器：

```tideweave
fn deterministic() -> Int =
  handle noisy_add(2, 3)
  with Rand.fixed(seed = 42) {
    rand.int(lo, hi) => continue(lo)
  }
```

## 3. 基础语法

### 3.1 函数定义

```tideweave
fn add(x: Int, y: Int) -> Int =
  x + y
```

管道风格：

```tideweave
fn inc_all(xs: List[Int]) -> List[Int] =
  xs
  |> map(fn x => x + 1)
  |> filter(fn x => x > 0)
```

### 3.2 模式匹配

```tideweave
type Shape =
  | Circle(Float)
  | Rect(Float, Float)

fn area(s: Shape) -> Float =
  match s {
    Circle(r) => 3.14159 * r * r
    Rect(w, h) => w * h
  }
```

### 3.3 模块与织纹

模块导出接口，并携带能力约束：

```tideweave
module Forest exposing (Tree, map, fold)

use Thread
use Stream as S
```

模块组合不叫 import 链，而叫“织纹链”：

```tideweave
weave Forest into App
weave Http into App
weave Log into App
```

每个模块声明自己需要和提供的效应能力，编译器检查织纹后是否满足。

## 4. 一个完整示例

```tideweave
module Counter exposing (main)

use Std.Io
use Std.List
use Std.Int

type Msg =
  | Add(Int)
  | Reset

type Model = {
  value: Int
}

fn update(model: Model, msg: Msg) -> Model =
  match msg {
    Add(n) => model { value = model.value + n }
    Reset  => model { value = 0 }
  }

fn view(model: Model) -> Text =
  "当前计数：{model.value}"

fn main() -> () !{io} =
  let initial = { value = 0 } in
  let next = update(initial, Add(3)) in
  io.println(view(next))
```

## 5. 编译与运行时

潮织可编译到 WebAssembly 与 LLVM IR。运行时包含：

- 工作窃取调度器；
- 结构化并发 `tide`；
- 效应处理器栈；
- 线性资源检查；
- 垃圾回收与借用优化并存；
- 确定性的错误取消与重试机制。

工具链：

- 包管理器：`shuttle`
- 格式化器：`weaver fmt`
- 语言服务器：`weaver lsp`
- 测试器：`weaver test`
- 文档生成器：`weaver doc`

## 6. 语言定位

潮织不是一个追求“最少语法”的函数式语言，而是一个把**函数、效应、并发、资源与模块组合**统一到“织”的隐喻中的语言：

- 函数是织梭；
- 值是纹理；
- 效应是光谱；
- 并发是潮汐；
- 类型是晶格；
- 模块是织纹；
- 程序是一次从种子到展开的折叠。

它的目标不是替代所有现有语言，而是探索一种更直观的、可静态检查的、兼顾纯函数式表达力与并发资源安全的新语言形态。

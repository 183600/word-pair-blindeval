# 全新函数式编程语言：织澜 Loom

**文件后缀**：`.loom`  
**一句话定位**：把程序看成可逆、可观测、带潮汐效应的编织过程。  
**主要灵感来源**：星火/折纸、潮汐/齿轮、镜面/种子、织机/并发、对仗/对偶、观测/坍缩、熵/秩序、时间/折叠。

## 1. 设计目标

Loom 是一门静态类型、纯函数式、惰性求值、支持代数效应与可逆函数的语言。它的独特之处在于把以下四件事统一起来：

1. **对偶优先**：数据类型与余数据类型、值与协值、正向函数与逆向函数都被统一看待。
2. **编织式组合**：普通函数是“梭子”，流与数据流是“经纬线”，程序通过管道编织成图。
3. **潮汐效应**：副作用被建模为 tide，可被 handler 捕获、前进、回退和恢复。
4. **增量可观测计算**：表达式形成带指纹的惰性图，修改输入只重算受影响的子图。

## 2. 核心语法示意

### 模块与函数

```loom
module Main
import Console

fn factorial(n: Int) -> Int =
  match n {
    0 => 1
    _ => n * factorial(n - 1)
  }

fn main() -> Unit -[Console]> =
  println("你好，织澜")
```

### 类型声明

```loom
type Nat = Z | S(Nat)

type Person = {
  name: Text,
  age: Int
}

type Tree[A] =
  | Leaf
  | Node(Tree[A], A, Tree[A])
```

### 类型系统

```text
A, B ::=
  Int | Bool | Text | Unit
  | A -> B              -- 纯函数
  | A -[E]-> B          -- 带效应行的函数
  | (A, B)              -- 积
  | A | B               -- 和
  | [A]                 -- 列表
  | Stream[A]           -- 惰性、可增量更新的流
  | A <-> B             -- 可逆同构
  | {x: A, y: B}        -- 记录
```

效应行 `E` 是行多态：

```loom
fn read_all(path: Path) -> [Text] -[File, Error]> =
  ...
```

## 3. 关键特性

### 3.1 可逆函数 `bi`

用 `bi` 声明可逆函数。编译器检查它是否为结构化双射，并自动生成 `inv`。

```loom
bi fn swap((a, b): (A, B)) -> (B, A) =
  (b, a)

-- 自动可用：
-- inv swap : (B, A) -> (A, B)
```

可逆函数是 Loom 的“镜面”特性：适用于编码、序列化、编辑器变换、状态迁移和增量计算。

### 3.2 潮汐效应 tide

效应声明：

```loom
tide Counter {
  next() -> Int
}
```

使用效应：

```loom
fn tag(x: Text) -> (Int, Text) -[Counter]> =
  (next(), x)
```

处理器：

```loom
handle Counter with n = 0 {
  next() =>
    resume(n) with n = n + 1
} in {
  tag("a")
}
```

`resume` 表示继续执行；Loom 还允许受线性资源约束的 `rewind`，使某些事务型计算可以回退。这样效应不仅是副作用描述，也可以表达“潮汐”式的前进与回退。

### 3.3 流与增量计算

```loom
stream fib: Stream[Int] =
  unfold((0, 1), \(a, b) =>
    (a, (b, a + b))
  )
```

数据流管道：

```loom
flow word_count(path: Path) -> Map[Text, Int] =
  read_lines(path)
    |> flat_map(split_words)
    |> fold(Map.empty, \(m, w) =>
         Map.update(m, w, 0, \(n) => n + 1)
       )
```

`Stream[A]` 是拉取式、带背压和记忆化的。编译器为每个节点维护指纹，输入变化时只让受影响的子图“退潮”，再重新涨潮计算。

### 3.4 编织并发

Loom 内置 `weave` 块，用于表达数据流并行：

```loom
weave {
  source |> parse ~> parsed
  parsed |> enrich ~> enriched
  enriched |> validate ~> result
}
```

`~>` 表示带背压的流连接。并发只发生在纯计算或显式允许的 tide 中，避免隐式副作用竞争。

### 3.5 对偶模式

模式匹配支持普通模式，也支持对偶模式。对偶模式用于在可逆结构上“反向解构”：

```loom
match packet {
  Encode(payload) => ...
  dual Decode(payload) => ...
}
```

在核心语义中，和类型与其对偶、构造与其观察、正向函数与其逆函数共享同一套类型规则。

## 4. 求值模型

Loom 的运行时可概括为：

```text
源码
  -> 解析为对偶抽象语法树
  -> 类型检查：HM + 行多态 + 线性/仿射资源 + 可逆性证明
  -> 降为 Loom Graph
  -> 惰性图归约 + 效应处理器栈 + 增量记忆化
```

核心 IR 节点包括：

```text
Value, App, Lambda,
Pair, Project, Inject, Match,
EffOp, Handle, Resume,
Stream, Unfold, Weave,
Memo, Fingerprint
```

纯表达式默认惰性；`force` 可显式求值。效应由分隔续延实现。流是拉取式迭代器与记忆化图的组合。`bi` 函数要求可判定可逆性，递归可逆函数需提供终止证明或显式逆函数。

## 5. 示例：状态计数器

```loom
tide Counter {
  next() -> Int
}

fn label_all(xs: [Text]) -> [(Int, Text)] -[Counter]> =
  map(xs, \(x) => (next(), x))

handle Counter with n = 0 {
  next() =>
    resume(n) with n = n + 1
} in {
  label_all(["甲", "乙", "丙"])
}
```

结果概念上为：

```text
[(0, "甲"), (1, "乙"), (2, "丙")]
```

## 6. 实现计划

1. **解析器**：递归下降，语法保持小核心 + 可扩展管道。
2. **类型检查器**：先实现 HM + ADT + 记录 + 效应行，再加入 `bi` 可逆性检查与线性资源。
3. **解释器**：CEK 机器 + 分隔续延 + 惰性 thunk + 指纹记忆化。
4. **运行时**：工作窃取调度器；流节点带需求令牌和背压。
5. **后端**：先解释执行；稳定后编译到 WebAssembly/Rust runtime，效应通过 CPS 或续延表实现。
6. **测试**：对 `bi` 函数做属性测试 `inv f (f x) == x`；对效应处理器检查恢复律；对纯图归约检查合流性。

## 7. 语言气质

Loom 不是“再加一个语法糖的函数式语言”，而是把**可逆性、效应、流、增量图**放进同一个核心：

- 用 `bi` 表达“镜面”；
- 用 `tide` 表达“潮汐”；
- 用 `Stream` 表达“经纬线”；
- 用 `weave` 表达“织机”；
- 用对偶类型与模式表达“对仗”；
- 用指纹与记忆化表达“年轮”；
- 用 handler 的恢复与回退表达“观测/坍缩”。

它的最终口号是：

> **把计算编成可逆的布，让效应像潮汐一样被看见。**

# 推荐 Idea：**「snippet-box」—— 终端命令片段收藏与智能复用工具**

**灵感来源**：第68组（命令-收藏）+ 第69组（片段-复用）+ 第67组（历史-搜索）

## 核心功能
- `sb save` —— 把刚执行的命令一键保存为带描述和标签的片段
- `sb find` —— 模糊搜索（fzf 风格交互界面），选中即填入命令行
- `sb run <name>` —— 支持参数占位符，如 `ssh {{user}}@{{host}}`，运行时交互式填空
- 从 shell history 智能挖掘高频长命令，主动建议"要不要收藏这个？"

## 为什么适合独立开发者
1. **痛点真实**：每个开发者都有反复敲长命令、翻 history 的经历
2. **范围可控**：单机 CLI + 本地 SQLite/JSON 存储，无需后端，一人可完成 MVP
3. **技术栈简单**：Go/Rust 单二进制分发，配合 Bubble Tea 或 fzf 做交互
4. **可扩展变现**：后续可加团队片段同步、加密分享、shell 插件市场等付费功能
5. **差异化**：相比 pet、tldr，主打"智能挖掘 + 参数化模板 + 一键回填"

# 认知温差理论（Cognitive Temperature Gradient Theory）

一个关于"创造力从何而来"的新假说。

## 核心命题

**创造力不取决于你拥有多少知识，而取决于你脑中不同"认知温度"区域之间的温差。**

就像热机需要温差才能做功，大脑产生新想法需要"热区"（熟悉、活跃、高频使用的知识）与"冷区"（陌生、休眠、被忽略的知识）之间的落差。温差越大，知识流动越剧烈，越容易产生新组合。

## 三个基本假设

1. **知识有温度**：频繁使用的概念是"热"的，久不使用的是"冷"的。温度随使用频率动态变化。
2. **想法是热交换的产物**：当一个热概念被迫与一个冷概念接触（例如被问到跨界问题），界面处会产生"认知湍流"——这就是灵感的物理本质。
3. **同质化导致热平衡**：如果一个人的输入全部来自同一领域，整个大脑趋于等温，创造力随之枯竭。这解释了"信息茧房"为何扼杀创新。

## 可检验的预测

| 预测 | 检验方式 |
|------|----------|
| 跨领域阅读者比单一领域深度阅读者产生更多"远距联想" | 远程联想测验（RAT）对照实验 |
| 长期只刷同质化内容后，创造力下降，且可通过"冷知识冲击"部分恢复 | 纵向追踪 + 干预实验 |
| 团队中知识背景差异越大，创新产出越高，但沟通成本也越高——存在最优温差 | 团队创新实验 |

## 一个反直觉推论

**"遗忘"可能是一种保护机制**：它让旧知识降温，从而在你重新接触它时制造温差，让旧知识以新面貌参与创造。这解释了为什么"放一放再想"（酝酿效应）常常有效——不是潜意识在偷偷工作，而是知识在"冷却"，等你回来时温差已经形成。

# 信息引力假说（Informational Gravity Hypothesis）

## 核心命题

**信息的聚集本身会产生一种类似引力的效应，塑造物质和行为的分布。**

## 理论框架

### 1. 基本假设

任何系统中，信息密度越高的区域，对其他信息载体（人、资本、粒子、注意力）的"吸引力"越强。这种吸引力可以用类似引力定律的形式描述：

$$F = G_i \cdot \frac{I_1 \cdot I_2}{d^2}$$

其中：
- $F$ = 信息吸引力
- $I_1, I_2$ = 两个节点的信息密度
- $d$ = 信息距离（不一定是物理距离，可以是语义距离、社交距离）
- $G_i$ = 信息引力常数（依领域而定）

### 2. 可观察的现象对应

| 领域 | 现象 | 理论解释 |
|------|------|----------|
| 城市学 | 大城市持续吸引人口 | 城市是高信息密度体 |
| 互联网 | 流量向头部平台集中 | 平台是信息引力中心 |
| 物理学 | 黑洞信息悖论 | 极端信息密度产生极端引力 |
| 生物学 | 大脑进化出沟回 | 在有限空间内最大化信息密度 |

### 3. 三个可检验的预测

1. **信息逃逸速度**：一个系统要让成员离开，必须提供超过临界值的新信息增量（解释为什么人们难以离开社交媒体）
2. **信息透镜效应**：信息在传播经过高密度节点时会发生"弯曲"（即被扭曲、重新解读）
3. **信息热寂**：如果一个封闭系统信息密度均匀化（熵最大），系统活动将停止——创新只发生在信息密度差存在的地方

### 4. 潜在应用

- **城市规划**：设计"信息密度梯度"来引导人口流动
- **AI 对齐**：理解智能体为何自发聚集于高信息环境
- **对抗信息垄断**：引入"反引力"机制（强制信息扩散）

## 理论的局限（自我批判）

- 信息密度的量化方式尚未定义
- 可能只是对已有现象的事后类比，而非真正的新机制
- 需要在某个具体领域（如社交网络数据）做定量验证

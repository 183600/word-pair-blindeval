# 信息引力理论（Informational Gravity Theory）

我来提出一个跨学科的假说性理论，供探讨。

## 核心命题

**信息本身具有"引力"——信息的密度差异会产生一种作用于认知系统（人、AI、社会）的"吸引力"，驱动注意力和资源的流动。**

## 基本假设

1. **信息密度场**：任何环境中，信息并非均匀分布。高信息密度区域（如大城市、互联网热点、学术中心）形成"信息势阱"。

2. **注意力即质量**：认知主体（人或智能体）的注意力相当于"质量"，会自发向信息高密度区域"坠落"。

3. **信息熵与斥力**：过度拥挤的信息环境产生熵增，形成"斥力"，将部分注意力推开——这解释了信息过载导致的逃离现象（如"数字排毒"）。

## 可检验的预测

- **预测一**：社交媒体用户的注意力分布应遵循类似引力定律的衰减规律——关注度 ∝ 信息量 / 认知距离²
- **预测二**：当一个信息源密度超过临界值（信息过载阈值），会出现"事件视界"——外部信息无法再进入该群体的认知（类似信息茧房的形成机制）
- **预测三**：创新往往发生在两个高密度信息区之间的"引力平衡点"（拉格朗日点）——即学科交叉地带

## 局限与待验证之处

- "信息密度"和"认知距离"的严格数学定义尚待建立
- 与现有的注意力经济理论、网络科学的关系需要厘清

# Idea：`devlog` —— 开发者的"工作日志"自动生成工具

## 核心痛点
开发者经常需要写日报、周报、更新简历或准备绩效材料，但总是想不起来"我上周到底干了什么"。

## 解决方案
一个 CLI 工具，自动从你的开发活动中提取信息，生成可读的工作日志：

```bash
$ devlog week
📅 本周工作总结（自动生成）

- 完成用户认证模块重构（12 commits, feature/auth 分支）
- 修复支付回调的并发 bug（PR #234）
- 优化首页加载速度，LCP 从 3.2s 降至 1.8s
```

## 数据来源
- **Git 历史**：commit message、分支切换、PR 合并
- **本地文件**：项目目录的活跃时间、编辑的文件类型
- **可选集成**：GitHub/GitLab API、Linear/Jira issue 状态

## 为什么适合独立开发者

1. **技术门槛低**：核心是解析 git log + 调用 LLM API 做摘要（可选），MVP 一周能做完
2. **自己就是用户**：dogfooding，需求理解深刻
3. **清晰的付费点**：
   - 免费版：本地 git 分析
   - Pro 版（$5/月）：LLM 润色、多平台集成、导出 Notion/飞书格式
4. **差异化**：市面上类似工具（如 Standuply）偏团队管理，个人向的轻量工具很少
5. **可扩展**：后续可加"专注时间统计"、"技术栈雷达图"等

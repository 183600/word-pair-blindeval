# 💡 Idea:**`devlog` — 开发者工作日志自动生成工具**

## 一句话描述
一个 CLI 工具,自动从你的 Git 提交、TODO 注释、终端历史中生成"今日/本周工作总结",帮你解决"写日报/周报/简历素材"的痛苦。

## 为什么适合独立开发者?

| 维度 | 分析 |
|------|------|
| **痛点真实** | 程序员普遍讨厌写日报、周报,但又有这个需求(求职复盘、自由职业向客户汇报) |
| **技术门槛适中** | 解析 git log + 文件扫描 + 调用 LLM API,一个人 2-4 周能出 MVP |
| **易于传播** | CLI 工具天然适合在 Hacker News、V2EX、掘金传播 |
| **可变现** | 本地功能免费,AI 总结/云端同步走订阅制 |

## 核心功能(MVP)

```bash
# 生成今天的工作摘要
$ devlog today

## 2025-01-15 工作总结
- 🔧 auth模块:修复了token过期未刷新的bug (3 commits)
- ✨ 新增用户导出CSV功能 (5 commits, +420 行)
- 📝 遗留TODO:支付模块还有2个FIXME未处理

# 生成周报(可接入 LLM 润色)
$ devlog week --ai --format markdown

# 导出为简历素材
$ devlog export --since 2024-01-01 --style resume
```

## 技术栈建议
- **语言**:Go 或 Rust(单二进制分发,零依赖)
- **数据源**:`git log`、代码中的 `TODO/FIXME`、可选接入 GitHub API
- **AI 层**:支持 OpenAI / Claude / 本地 Ollama(用户自带 key)

## 差异化亮点
1. **隐私优先**:纯本地运行,代码不出本机(AI 功能可选)
2. **多种输出**:Markdown、飞书/钉钉格式、英文简历风格
3. **「成就模式」**:自动提炼"量化成果",如"本月重构 X 模块,删除 2000 行冗余代码"

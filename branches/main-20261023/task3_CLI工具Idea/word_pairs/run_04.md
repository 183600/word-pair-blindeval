**💡 CLI 工具 Idea：`devpulse` —— 开发者工作流健康仪表盘**

**灵感来源**：第3组（时间追踪）、第43组（提交统计）、第63组（TODO收集）、第101组（倒计时提醒）、第21组（番茄钟专注）

**一句话描述**：一条命令，汇总你本地开发环境的全景健康报告。

**核心功能**：
- `devpulse scan`：扫描当前项目，输出 Git 提交频率、未提交改动天数、积压 TODO/FIXME 数量、依赖过期情况、测试覆盖率变化趋势
- `devpulse focus`：内置番茄钟，自动记录每个项目的深度工作时间，与 Git 提交关联
- `devpulse stale`：找出本地超过 N 天没碰的"僵尸项目"和未推送的分支
- `devpulse report --week`：生成周报（Markdown），可直接粘贴到团队群或博客

**为什么适合独立开发者做 CLI**：
1. **纯本地运行**，无需服务器，零运维成本
2. 数据源都是现成的（Git 仓库、文件系统），不需要爬虫或第三方 API
3. 单机 MVP 一两周可完成，后续可加 TUI 界面、插件系统做差异化
4. 目标用户（开发者）就在终端里，获客渠道清晰（Hacker News、Reddit、掘金）

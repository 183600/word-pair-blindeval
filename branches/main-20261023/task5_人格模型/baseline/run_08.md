# 「四源八相」人格动力模型（Tetra-Source Model）

## 一、理论基础

不同于九型人格以"核心恐惧/欲望"为轴、荣格八维以"认知功能"为轴，本模型提出：人格由**四种心理能量源泉**驱动，每个人拥有独特的主次配置，并在成长过程中经历"相位转化"。

**核心假设**：人的行为动机可还原为四种元能量——

| 能量源 | 核心追问 | 对应驱力 |
|--------|---------|---------|
| 🔥 **焰（Ignis）** | "我能改变什么？" | 行动、征服、创造影响 |
| 🌊 **流（Flux）** | "我感受到什么？" | 共情、联结、体验深度 |
| 🪨 **岩（Terra）** | "什么是可靠的？" | 秩序、积累、安全感 |
| 💨 **风（Aer）** | "这意味着什么？" | 意义、抽象、可能性 |

## 二、八相结构（类似荣格八维）

每种能量有两种运行**相位**：

- **焰**：外焰（开拓竞争）/ 内焰（自我淬炼）
- **流**：涌流（向外共情给予）/ 深流（向内体验反刍）
- **岩**：筑岩（建立规则体系）/ 藏岩（守护内在领地）
- **风**：扬风（发散联想探索）/ 旋风（逻辑解构分析）

由此构成八种功能相位，每人拥有一个**主相**、一个**辅相**、一个**弱相**、一个**影相**（被压抑但压力下爆发）。

## 三、类型生成

主相 × 辅相 = 8×7 = **56种类型**，例如：

- **外焰·扬风型**：开拓者——用愿景点燃行动，创业家原型
- **深流·藏岩型**：守夜人——情感深沉内敛，忠诚而隐秘
- **旋风·筑岩型**：建筑师——用逻辑构建体系，制度设计者

## 四、动态机制（区别于静态类型学）

1. **压力转化**：压力下主相退行为对应的"影相"（如外焰型压力下变成失控的旋风——过度分析瘫痪）
2. **成长路径**：健康整合的方向是发展"对角相位"（外焰者需修习深流）
3. **季节循环**：人生不同阶段主导能量自然轮替（青年多焰风、中年多岩、老年多流）

## 五、与现有模型的对应关系

- 焰 ≈ 九型的3/7/8号能量 + Te/Se
- 流 ≈ 2/4/9号 + Fi/Fe
- 岩 ≈ 1/5/6号 + Si/Ti
- 风 ≈ 5/7号 + Ne/Ni

但本模型强调**能量而非功能**，解释"为什么做"而非"如何加工信息"。

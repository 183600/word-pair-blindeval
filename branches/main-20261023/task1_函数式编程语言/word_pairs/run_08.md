# 第二部分：全新函数式编程语言 —— **汐（Xī / Tide）**

## 设计理念（从词组中提炼）

| 灵感来源 | 语言特性 |
|---|---|
| 潮汐·月亮、河流·分支 | 数据如潮汐般**单向流动**，分支即河道分汊 |
| 种子·发芽、递归·基例 | 一切计算是"生长"：`seed` + `grow` |
| 惰性·按需、沙漏·细颈 | 默认惰性求值，流如沙漏 |
| 不可变·持久、年轮·气候 | 值一旦形成即"年轮"，只可新增不可改写 |
| 模式·匹配、榫卯·咬合 | 模式匹配即"榫卯咬合"，形状不合即拒绝 |
| 管道·流、运河·船闸 | 管道操作符 `\|>` 如船闸逐级放行 |
| 量子·叠加、波函数·坍缩 | 惰性值是"叠加态"，求值即"坍缩" |
| 留白·意境、侘寂·不完美 | 语法极简，缩进即结构，允许部分函数"留白待补" |
| 发酵·时间、腌制·时间 | 内置**时间感知的惰性流**（`ferment`） |
| 金缮·锔瓷 | 错误处理哲学：`mend`——错误不是断裂，而是被"金缮"修复并留下痕迹 |

## 核心语法

### 1. 值绑定 —— 年轮（不可变）
```xī
let 圆周率 = 3.14159
let 问候 = "你好，潮汐"
-- 没有变量，只有名字；重新绑定即新年轮
```

### 2. 函数 —— 种子与生长
```xī
-- 定义：seed 是参数，grow 是体
grow 阶乘 (0)        = 1
grow 阶乘 (n)        = n * 阶乘 (n - 1)

-- 柯里化天然支持
grow 加 a b = a + b
let 加五 = 加 5
```

### 3. 管道 —— 运河船闸
```xī
let 结果 =
    [1..100]
    |> 过滤 偶数?
    |> 映射 (\x -> x * x)
    |> 折叠 (+) 0
-- 数据如船，逐级过闸
```

### 4. 模式匹配 —— 榫卯
```xī
榫卯 描述 (列表) =
    | []        -> "空匣"
    | [x]       -> "独木"
    | [x, y]    -> "对偶"
    | (h :: t)  -> "首 " ++ 显示 h ++ "，尾续"
```

### 5. 类型 —— 晶体生长
```xī
晶体 树 a =
    | 叶
    | 枝 (树 a) a (树 a)

晶体 河流 a =
    | 源头 a
    | 汇流 (河流 a) (河流 a)
    | 改道 (a -> b) (河流 a)   -- 高阶：河流可改道
```

### 6. 惰性流 —— 沙漏与潮汐
```xī
let 自然数 = 潮汐 0 (\n -> n + 1)     -- 无限流，按需坍缩
let 斐波 = 发酵 [0, 1] (\[a,b] -> a + b)  -- 时间发酵的流

取 10 自然数 |> 转列表   -- 只有此处发生"坍缩"
```

### 7. 错误处理 —— 金缮（mend）
```xī
晶体 缮 e a =
    | 完 a          -- 完好
    | 缮 e a        -- 有裂痕但被金线修复，仍可用
    | 碎 e          -- 彻底破碎

金缮 安全除 x y =
    | y == 0  -> 碎 "除零之裂"
    | 否则    -> 完 (x / y)

-- 金缮链：裂痕会累积成"金线日志"
let r = 安全除 10 2 >>= 加 1 |> 留痕
-- r = 完 6 ，金线 = []
```

### 8. 效应系统 —— 季风（声明式效应）
```xī
效应 读写文件 : 季风 IO

grow 主程序 : IO ()
grow 主程序 = do
    内容 <- 扬起 (读文件 "诗.txt")   -- 扬起 = 触发效应
    扬起 (写文件 "副本.txt" 内容)
-- 效应如季风：可见、可拦截、可替换（测试时换成"无风带"）
```

### 9. 并发 —— 候鸟与蚁群
```xī
-- 候鸟：轻量进程，随季节（调度器）迁徙
let 鸟群 = 放飞 [1..1000] (\n -> 耗时计算 n)
let 收获 = 归巢 鸟群        -- 等待全部归巢

-- 蚁群：信息素通道（channel）
let 通道 = 新信息素 ()
放信息素 通道 42
气味 <- 嗅探 通道
```

## 一个完整示例：词频统计

```xī
模块 词频 where

grow 统计 : 文本 -> [(词, 数)]
grow 统计 文 =
    文
    |> 分词
    |> 映射 小写
    |> 过滤 (非 停用词?)
    |> 聚类            -- 相同词聚为一簇
    |> 映射 (\簇 -> (首 簇, 长度 簇))
    |> 排序由 (降序 . 次)

主程序 = do
    文 <- 扬起 (读文件 "潮汐集.txt")
    印出 (统计 文)
```

## 语言特性总结

- **纯函数式、默认惰性**：一切皆叠加态，求值即坍缩
- **不可变年轮数据**，结构化共享
- **榫卯模式匹配** + **晶体代数数据类型**
- **金缮错误哲学**：错误可被修复并留下可见痕迹（带日志的 Either）
- **季风效应系统**：效应声明、可拦截、可替换
- **候鸟并发 + 信息素通道**
- **留白语法**：缩进即结构，无分号无大括号
- **侘寂精神**：允许 `留白`（hole）占位，编译器提示"此处待补"，类型推导照常工作

这门语言把"计算"重新想象为**自然过程**：数据如河流奔涌，函数如种子发芽，错误如瓷器金缮，并发如候鸟迁徙——代码即自然。

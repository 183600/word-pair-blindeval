# 低成本、无需训练即可大幅提升LLM性能的方法

从上面词对中提炼出**七大实战方向**：

## 1. 提示工程（性价比最高）
- **思维链（CoT）**：加一句"让我们一步步思考"，推理类任务准确率可提升10-30%
- **少样本示例**：给3-5个高质量输入输出示例，效果接近微调
- **角色设定+明确约束**：规定格式、长度、受众、禁止事项
- **结构化提示**：用XML/Markdown标签分隔指令、上下文、示例

## 2. 检索增强生成（RAG）
- 把知识库嵌入向量数据库，按需检索注入上下文
- 解决幻觉、知识过期、私有数据问题，**零训练成本**
- 配合查询改写、混合检索、重排序可再提升20%+

## 3. 采样与解码策略
- **自我一致性**：同一问题采样5-10次，多数投票取答案（推理任务显著提升）
- 调整temperature：事实任务用0-0.3，创意任务用0.7-1.0
- 设置合理的stop token和重复惩罚

## 4. 任务分解与多步推理
- 复杂任务拆成"规划→执行→检查"流水线
- 先生成大纲再填充内容（两阶段生成）
- 让模型先自我批评再修订（反思循环）

## 5. 工具调用（Agent化）
- 接计算器、代码解释器、搜索引擎，弥补模型算术/实时信息短板
- 函数调用让模型"会做"而不是"会说"

## 6. 上下文工程
- 关键信息放在开头和结尾（对抗"中间遗忘"）
- 压缩历史对话、剔除冗余，提高信息密度
- 用程序做后处理校验（JSON合法性、事实核对）

## 7. 系统级组合拳
- **模型级联**：简单问题用小模型，难题路由到大模型，成本降50%+
- **评估闭环**：建测试集→错误分析→针对性改提示，持续迭代
- **缓存复用**：相似查询直接命中缓存

**优先级建议**：提示工程 > RAG > 自我一致性 > 工具调用 > 系统优化。通常仅靠前两项就能让现有模型表现提升一个档次，且几乎零成本。

# CLI 工具 Idea：「env-doctor」—— 开发环境诊断与修复工具

## 一句话描述
一条命令扫描你的开发环境，找出配置问题并自动修复。

## 解决的真实痛点
开发者经常遇到这些问题：
- 换了新电脑，环境配置半天跑不起来项目
- "在我机器上能跑" —— 环境差异导致的诡异 bug
- Node/Python/Git 版本不对、PATH 配置错误、端口被占用、证书过期……

## 核心功能

```bash
$ env-doctor check

✔ Node.js v20.11.0 (满足项目要求 >=18)
✘ Python 3.8 已过期，项目需要 >=3.10
✘ 端口 3000 被进程 PID 4521 占用
⚠ Git 未配置 user.email
⚠ SSH key 未添加到 ssh-agent

运行 `env-doctor fix` 自动修复 3 个问题
```

- **check**：扫描常见开发工具链（Node、Python、Docker、Git、数据库等）
- **fix**：自动修复能修的问题（改 PATH、杀占用进程、补配置）
- **init**：在项目里生成 `env-doctor.yml`，声明项目所需环境，新成员一键自检
- **快照对比**：`env-doctor diff` 对比两台机器的环境差异

## 为什么适合独立开发者

1. **技术门槛低**：本质是调用系统命令 + 解析输出，用 Go/Rust/Node 都能写
2. **插件化架构易扩展**：每种工具链一个 checker，社区可以贡献插件
3. **你自己就是目标用户**：容易做出真正好用的东西
4. **CLI 分发简单**：单二进制文件，brew/scoop/npm 都能发
5. **有商业化空间**：免费版检查本地环境，Pro 版做团队环境同步、CI 集成

## 差异化
现有工具（如 `doctor` 类脚本）大多只针对单一生态（如 React Native 的 doctor），做一个**通用、跨语言、可配置**的环境医生是空白点。

## 回答 B（cleaned_word_pairs）

# 💡 推荐 Idea：**`devpulse` — 开发者每日工作流自动复盘 CLI**

**灵感来源**：Git·统计（71）+ 番茄钟·专注（18）+ 复盘·模板（105）+ 灵感·速记（181）

## 核心功能

一条命令 `devpulse today`，自动汇总你今天作为开发者的所有痕迹：

- **Git 活动**：扫描本地所有仓库，汇总今天的 commit、分支切换、代码增删行数
- **时间分布**：按项目/语言统计编码时间（类似本地版 WakaTime，无需联网）
- **终端历史**：分析 shell history，统计你最常用的命令、踩过的坑（报错命令）
- **一键日报**：基于以上数据，用模板生成 Markdown 日报/周报，可直接贴进飞书、Notion

## 为什么适合独立开发者

1. **纯本地、无后端**：只读 git 仓库和 shell history，零服务器成本
2. **技术栈简单**：Go/Rust 单二进制分发，或 Node.js 通过 npm 分发
3. **痛点真实**：开发者写日报/周报是普遍痛点，"我昨天干了啥"是高频问题
4. **可扩展变现**：免费版本地统计；Pro 版可加 AI 生成总结、团队聚合看板
5. **易传播**：终端输出漂亮的 TUI 报告，天然适合在 Twitter/掘金截图分享

## 差异化

WakaTime 需要联网和编辑器插件；`devpulse` 主打**离线优先 + git 维度 + 一键生成可分享的工作报告**，定位"开发者的 journaling 工具"。

# Idea：`devlog` —— 开发者的"工作日志"自动生成工具

## 核心痛点
开发者经常需要写日报、周报、更新简历或准备绩效材料，但总是想不起来"我上周到底干了什么"。

## 解决方案
一个 CLI 工具，自动从你的开发活动中提取信息，生成可读的工作日志：

```bash
$ devlog week
📅 本周工作总结（自动生成）

- 完成用户认证模块重构（12 commits, feature/auth 分支）
- 修复支付回调的并发 bug（PR #234）
- 优化首页加载速度，LCP 从 3.2s 降至 1.8s
```

## 数据来源
- **Git 历史**：commit message、分支切换、PR 合并
- **本地文件**：项目目录的活跃时间、编辑的文件类型
- **可选集成**：GitHub/GitLab API、Linear/Jira issue 状态

## 为什么适合独立开发者

1. **技术门槛低**：核心是解析 git log + 调用 LLM API 做摘要（可选），MVP 一周能做完
2. **自己就是用户**：dogfooding，需求理解深刻
3. **清晰的付费点**：
   - 免费版：本地 git 分析
   - Pro 版（$5/月）：LLM 润色、多平台集成、导出 Notion/飞书格式
4. **差异化**：市面上类似工具（如 Standuply）偏团队管理，个人向的轻量工具很少
5. **可扩展**：后续可加"专注时间统计"、"技术栈雷达图"等

## 冷启动建议
- 用 Rust 或 Go 写，单二进制分发
- 先在 Hacker News / V2EX / 掘金发"我用 CLI 自动生成周报"的帖子
- 开源核心 + 付费云同步是不错的模式

## 回答 B（cleaned_word_pairs）

## CLI 工具 Idea：**devreplay —— 终端会话录制与回放工具**

**灵感来源**：响应-录制(54)、日志-收集(85)、录屏-转GIF(143)、文档-生成(32)、管道-触发(93)

### 核心概念
一个轻量级 CLI 工具，录制你在终端中的操作会话（命令 + 输出），并支持：

1. **`devreplay record`** — 录制终端会话为结构化文件（JSON），而非视频，体积小、可 diff、可提交到 Git
2. **`devreplay play`** — 本地回放会话，模拟打字效果，用于演示或教学
3. **`devreplay to-gif / to-svg`** — 一键导出为 GIF/SVG 动画，嵌入 README
4. **`devreplay to-doc`** — 自动把会话转成 Markdown 教程文档（命令 + 输出 + 注释）
5. **`devreplay to-script`** — 从录制中提取命令生成可执行的 shell 脚本
6. **`devreplay assert`** — 把录制当作"快照测试"：CI 中重新执行命令，对比输出是否一致，用于验证文档中的命令是否仍然有效

### 为什么适合独立开发者
- **技术门槛适中**：基于 PTY 捕获，Rust/Go 均可实现，无复杂依赖
- **差异化**：相比 asciinema（只回放），它打通了「录制 → 文档 → 脚本 → 测试」的完整链路
- **痛点真实**：开发者写 README 教程、排查"在我机器上能跑"问题、验证文档过时命令，都是高频痛点
- **可扩展变现**：免费开源核心 + 付费云端分享/团队协作功能

### 最小可行版本（MVP）
先做 `record` + `play` + `to-doc` 三个命令，一周即可完成原型。

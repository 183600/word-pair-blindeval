## 回答 A（baseline）

# 分形记忆Transformer(Fractal Memory Transformer, FMT)

## 核心思想

现有Transformer有两个痛点:**注意力复杂度O(n²)**和**缺乏跨时间尺度的记忆**。我提出一种结合**分形层级结构**与**可微分外存**的架构。

---

## 架构设计

### 1. 分形注意力层(Fractal Attention)

将序列组织成自相似的多尺度结构:

```
Level 0: [tok][tok][tok][tok][tok][tok][tok][tok]
Level 1:    [---块1---]       [---块2---]
Level 2:         [------超级块------]
```

- 每个token只与**同层邻居**和**上下层的摘要节点**交互
- 复杂度降至 **O(n log n)**
- 信息通过"摘要token"在层级间双向流动(自底向上压缩,自顶向下广播)

### 2. 可微分记忆库(Differentiable Memory Bank)

- 维护一个外部记忆矩阵 **M ∈ R^(k×d)**,通过**内容寻址**读写
- 写入:对重要信息(用学习到的"显著性分数"筛选)进行压缩存储
- 读取:查询时用稀疏注意力检索 top-m 条目
- 记忆在**推理时也可持续更新**,实现类似"终身学习"的效果

### 3. 时间自适应计算(Adaptive Depth)

- 每个token独立决定"思考深度":简单token早退,困难token进入更深的递归处理
- 用强化学习或直通估计器训练深度决策

---

## 关键创新点

| 模块 | 解决的问题 |
|------|-----------|
| 分形注意力 | 长序列效率,同时保留全局信息流 |
| 记忆库 | 突破上下文窗口限制,知识可积累 |
| 自适应深度 | 计算资源按需分配,推理更快 |

## 训练策略

1. **课程学习**:先训短序列单层,逐步展开分形层级
2. **记忆正则化**:对记忆写入加稀疏惩罚,防止记忆爆炸
3. **蒸馏初始化**:用预训练标准Transformer初始化底层参数

## 潜在应用

- 超长文档/代码库理解(百万级token)
- 持续对话智能体(跨会话记忆)
- 科学文献的增量知识整合

## 回答 B（cleaned_word_pairs）

## 新架构：**潮汐根系网络（Tidal-Root Network, TRN）**

从以上词对中提炼三个核心灵感：**根系-吸收**（多尺度分层提取）、**潮汐-节奏**（周期性的信息涨落）、**菌丝-联网**（动态稀疏连接）。

### 核心设计

**1. 根系式多尺度输入层（Root Layer）**
输入不被切成固定 patch，而是像根系一样长出不同粗细的"根须"：粗根捕获全局结构（低分辨率大感受野），细根须深入局部细节（高分辨率小感受野）。每条根须是一个轻量卷积/注意力分支，根须的粗细与数量由输入复杂度自适应分配（受"蚁群-觅食"启发：信息密集区域自动分配更多计算）。

**2. 潮汐门控机制（Tidal Gating）**
替代固定的前向深度。网络在"涨潮"与"退潮"两个相位间交替：
- **涨潮期**：信息自底向上汇聚，层间全连接激活，类似标准前向传播；
- **退潮期**：信息自顶向下回流，高层语义反向调制低层特征（受"梦境-重组"与"回声-延迟"启发）。

每个样本经历 K 个潮汐周期（K 可学习或按置信度早停，受"蜂巢-协作"与"免疫-识别"启发：一旦高层对预测置信度超过阈值即停止，节省算力）。

**3. 菌丝动态稀疏连接（Mycelium Routing）**
层与层之间不是固定全连接，而是维护一个稀疏"菌丝图"：训练初期连接密集，随训练进行，弱连接像"藤蔓-攀援"中无支撑的卷须一样枯萎（幅值低于阈值即剪除），强连接加粗并允许"嫁接-结合"——两条高频共激活的通路融合为一条更宽的通路。这使网络结构在训练中持续生长与重构（受"珊瑚-生长"启发）。

**4. 年轮记忆池（Ring Memory）**
受"年轮-记录"启发，维护一个按时间分层的 episodic 记忆：近期经验存在外层（易读写、易覆写），久远但反复被检索的经验逐渐"沉积"到内层成为长期知识（类似"沉淀-分层"）。检索用"蝙蝠-回声"式机制：发出查询向量，按返回"回声"的强度与延迟加权读取。

### 训练目标
标准任务损失 + 三项正则：
- **潮汐一致性**：涨潮与退潮对同一输入的表征应互相预测（自监督）；
- **稀疏预算**：菌丝连接总量受约束（受"冬眠-降耗"启发）；
- **根系平衡**：粗细根须的梯度贡献趋于均衡，防止某一分支垄断。

### 预期优势
- **自适应计算**：简单样本早退潮，难样本多周期，天然实现动态深度；
- **结构可进化**：菌丝剪枝+嫁接让架构随数据生长，减少手工调参；
- **长程记忆**：年轮池缓解灾难性遗忘，适合持续学习；
- **可解释性**：可观察哪条根须、哪条菌丝通路主导了决策（"棱镜-分光"式归因）。

**一句话概括**：TRN = 像根一样吸收、像潮汐一样思考、像菌丝一样生长、像年轮一样记忆的动态稀疏网络。

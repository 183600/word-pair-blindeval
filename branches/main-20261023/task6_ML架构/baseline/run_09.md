# 分层记忆流网络(Hierarchical Memory-Stream Network, HMSN)

## 核心动机

现有架构存在两个痛点:
- **Transformer**:注意力随序列长度二次增长,长上下文成本高
- **RNN/状态空间模型**:长程记忆会被逐步稀释,难以精确检索远期信息

HMSN 试图结合两者的优点:**用流式状态处理当下,用可寻址记忆库保存过去**。

## 架构设计

### 1. 三层处理结构

```
输入序列
   │
   ▼
┌─────────────────┐
│  快流层 (Fast)   │  局部窗口注意力,处理最近 K 个 token
└────────┬────────┘
         │ 压缩写入
         ▼
┌─────────────────┐
│  慢流层 (Slow)   │  状态空间模型(SSM),维护滚动摘要状态
└────────┬────────┘
         │ 关键事件触发
         ▼
┌─────────────────┐
│  记忆库 (Memory) │  可微分的键值存储,长期保存重要信息
└─────────────────┘
```

### 2. 关键创新:学习式写入门控

不是每一步都写入记忆库,而是由一个**显著性评分器**决定:

$$s_t = \sigma(w^\top h_t), \quad \text{仅当 } s_t > \tau \text{ 时写入记忆库}$$

这模拟人类记忆——只记住"重要的事",使记忆库保持稀疏、可检索。

### 3. 读取机制:混合检索

读取时结合两种方式:
- **内容寻址**:用当前隐状态与记忆键做注意力
- **时间衰减偏置**:近期记忆获得轻微先验加权

$$m_t = \sum_i \text{softmax}\left(\frac{q_t k_i^\top}{\sqrt{d}} + \lambda \cdot \text{recency}_i\right) v_i$$

### 4. 输出融合

三个来源的信息通过门控融合:

$$o_t = g_1 \odot h_t^{\text{fast}} + g_2 \odot h_t^{\text{slow}} + g_3 \odot m_t$$

## 理论优势

| 特性 | Transformer | SSM | HMSN |
|------|------------|-----|------|
| 推理复杂度 | O(n²) | O(n) | O(n·log M) |
| 精确远期检索 | ✓ | ✗ | ✓ |
| 记忆容量可控 | ✗ | ✗ | ✓ |

## 训练策略

1. **课程学习**:先短序列训练快流层,再逐步拉长序列激活慢流层和记忆库
2. **记忆正则化**:对写入频率加稀疏惩罚,防止记忆库被噪声填满
3. **检索辅助损失**:在合成任务(如"复制 1000 步前的数字")上额外监督检索质量

## 潜在应用场景

- 超长文档/代码库理解
- 终身学习智能体(跨会话记忆)
- 视频理解(帧级快流 + 事件级记忆)

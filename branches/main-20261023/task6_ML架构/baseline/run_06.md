# 提出一种新架构:**MoSA — 混合稀疏注意力与状态空间架构**
**(Mixture of Sparse Attention + State-space Architecture)**

## 一、设计动机

当前主流架构各有短板:

| 架构 | 优势 | 短板 |
|------|------|------|
| Transformer | 全局注意力、并行训练 | O(n²) 复杂度,长序列昂贵 |
| Mamba/SSM | 线性复杂度、长序列高效 | 精确检索能力弱 |
| MoE | 参数高效、计算稀疏 | 路由不稳定、专家坍缩 |

**核心思想:让模型自己学会"什么时候该回忆、什么时候该压缩"。**

## 二、架构设计

### 1. 双通路混合块(核心单元)

每一层由两条并行通路组成,由**门控网络**动态加权:

```
输出 = g(x) · Attention(x) + (1 − g(x)) · SSM(x)
```

- **注意力通路**:稀疏注意力(如滑动窗口 + 少量全局 token),负责精确检索
- **SSM 通路**:负责长程压缩与序列建模
- **门控 g(x)**:逐 token 学习,简单重复内容走 SSM(便宜),需要精确引用的内容走注意力

### 2. 层级化记忆(三层记忆系统)

模仿人类记忆:

- **工作记忆**:当前窗口的 KV cache
- **情景记忆**:可检索的外部向量库(类似 RAG,但端到端训练,检索器与生成器联合优化)
- **语义记忆**:模型权重本身

### 3. 稀疏专家 + 共享专家

- 每层包含 **1 个共享专家**(所有 token 必经,保证基础能力)+ **N 个路由专家**
- 路由采用 **无辅助损失的偏置调节法**(参考 DeepSeek-V3),避免负载不均衡

### 4. 递归深度机制

- 简单 token 浅层即出,困难 token 循环经过同一块多次(类似 ACT / Universal Transformer)
- 用退出置信度控制计算量,实现**自适应计算深度**

## 三、训练策略

1. **课程学习**:先短序列预训练,逐步拉长上下文(128K → 1M)
2. **多目标损失**:语言建模损失 + 门控稀疏正则 + 退出深度惩罚(鼓励节能)
3. **检索-生成联合训练**:对情景记忆模块用对比学习微调检索器

## 四、预期优势

- **推理成本**:相比同规模 Transformer 降低 40–60%(门控 + 稀疏 + 早退三重节省)
- **长上下文**:SSM 通路天然支持百万级 token
- **可解释性**:门控权重可视化能揭示模型"在哪里用了注意力"

## 五、风险与开放问题

- 门控与路由双重离散决策可能导致训练不稳定 → 需 Straight-Through 估计或软化
- 联合训练检索模块工程复杂度高
- 自适应深度与并行训练存在矛盾,需要专门设计

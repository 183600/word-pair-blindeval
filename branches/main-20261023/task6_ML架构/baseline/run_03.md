# 分形记忆Transformer(Fractal Memory Transformer, FMT)

## 核心思想

现有Transformer有两个痛点:**注意力复杂度O(n²)**和**缺乏跨时间尺度的记忆**。我提出一种结合**分形层级结构**与**可微分外存**的架构。

---

## 架构设计

### 1. 分形注意力层(Fractal Attention)

将序列组织成自相似的多尺度结构:

```
Level 0: [tok][tok][tok][tok][tok][tok][tok][tok]
Level 1:    [---块1---]       [---块2---]
Level 2:         [------超级块------]
```

- 每个token只与**同层邻居**和**上下层的摘要节点**交互
- 复杂度降至 **O(n log n)**
- 信息通过"摘要token"在层级间双向流动(自底向上压缩,自顶向下广播)

### 2. 可微分记忆库(Differentiable Memory Bank)

- 维护一个外部记忆矩阵 **M ∈ R^(k×d)**,通过**内容寻址**读写
- 写入:对重要信息(用学习到的"显著性分数"筛选)进行压缩存储
- 读取:查询时用稀疏注意力检索 top-m 条目
- 记忆在**推理时也可持续更新**,实现类似"终身学习"的效果

### 3. 时间自适应计算(Adaptive Depth)

- 每个token独立决定"思考深度":简单token早退,困难token进入更深的递归处理
- 用强化学习或直通估计器训练深度决策

---

## 关键创新点

| 模块 | 解决的问题 |
|------|-----------|
| 分形注意力 | 长序列效率,同时保留全局信息流 |
| 记忆库 | 突破上下文窗口限制,知识可积累 |
| 自适应深度 | 计算资源按需分配,推理更快 |

## 训练策略

1. **课程学习**:先训短序列单层,逐步展开分形层级
2. **记忆正则化**:对记忆写入加稀疏惩罚,防止记忆爆炸
3. **蒸馏初始化**:用预训练标准Transformer初始化底层参数

## 潜在应用

- 超长文档/代码库理解(百万级token)
- 持续对话智能体(跨会话记忆)
- 科学文献的增量知识整合

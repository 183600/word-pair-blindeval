## CLI 工具 Idea：**`errx` —— 终端错误翻译官**

**灵感来源：** 第 47 组「错误/解释」+ 第 74 组「命令/学习」+ 第 133 组「对话/导出」

**一句话：** 把任何命令的报错输出，变成人话 + 可执行的修复建议。

**用法：**
```bash
$ errx npm install
# 或管道模式
$ cargo build 2>&1 | errx
```

**输出示例：**
```
❌ 错误：EACCES 权限不足（/usr/local/lib/node_modules）
💡 原因：全局安装使用了系统目录
🔧 修复（按推荐排序）：
  1. [推荐] 改用 nvm 管理 node，避免 sudo
  2. sudo chown -R $(whoami) /usr/local/lib/node_modules
📖 相关文档：https://docs.npmjs.com/...
```

**核心功能：**
- 内置常见工具（npm/git/docker/k8s/rustc/gcc…）的错误模式库，**离线可用**
- 可选接入 LLM，对未知错误做解释
- `errx --learn` 记录你踩过的坑和当时的解法，形成个人错误知识库
- 修复命令可直接 `errx fix 1` 一键执行

**为什么适合独立开发者：** 纯文本处理、无 UI 复杂度、可离线规则库起步、LLM 作为可选增强、易通过包管理器分发（brew/npm/pip），且开发者每天都在终端里被报错折磨——痛点真实、受众明确。

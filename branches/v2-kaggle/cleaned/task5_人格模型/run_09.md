## 第二部分：新模型——「四枢八相」人格模型（The Four Hinges Model）

从以上词组中反复出现的母题——**容器与内容、张与弛、藏与露、根与翼**——我提炼出一个新模型。

### 核心思想

九型问"你恐惧什么"，荣格问"你如何感知与判断"。本模型问的是第三个问题：

> **"你的心理能量在哪里'铰接'？你如何连接内在与外在？"**

如同门需要"枢"才能开合，人格也有四个"枢"（维度），每个枢有两种"相"（姿态）。

### 四枢（四个维度）

**① 锚枢（Anchor）——能量来源**
- 🜁 **根型（Rooted）**：从稳定、归属、传统中充电（灵感：根—叶、锚—船）
- 🜄 **潮型（Tidal）**：从变化、新奇、流动中充电（灵感：潮水—礁石、帆—风）

**② 镜枢（Mirror）——自我建构**
- 🜂 **炉型（Forge）**：通过"成为某种东西"定义自我，自我是作品（灵感：锤—砧、窑—瓷）
- 🜃 **潭型（Pool）**：通过"映照与体验"认识自我，自我是容器（灵感：潭—影、镜—面具）

**③ 门枢（Gate）——与他人的边界**
- **城型（Walled）**：边界清晰，信任需赢得，深度优先（灵感：城—池、锁—钥匙）
- **桥型（Bridged）**：边界通透，连接即本能，广度优先（灵感：桥—岸、网—鱼）

**④ 弦枢（String）——行动节律**
- **弓型（Drawn）**：蓄力—爆发式，长期压抑后集中释放（灵感：弓—箭、茧—蝶）
- **钟型（Pendulum）**：节律—摆荡式，在规律循环中推进（灵感：钟摆—静止、日—晷）

### 十六种"相"（组合类型示例）

| 组合 | 名称 | 核心写照 |
|---|---|---|
| 根·炉·城·弓 | **铸剑者** | 在归属中默默锻造自我，一击定音 |
| 潮·潭·桥·钟 | **渡灯人** | 在流动中映照众生，节律地连接 |
| 潮·炉·桥·弓 | **风暴匠** | 在变化中爆发式创造，广结善缘 |
| 根·潭·城·钟 | **古井** | 深守一方，以恒定节律映照岁月 |
| 根·炉·桥·钟 | **薪火者** | 在传承中锻造，稳定地温暖他人 |
| 潮·潭·城·弓 | **暗涌** | 表面流动，内心深藏，蓄力而观 |
| …（共16种） | | |

### 与九型、荣格的差异

1. **动态性**：四枢不是固定特质，而是"铰链"——人会沿枢摆动，模型测量的是**默认位置 + 摆动幅度**（如"城型但高摆动"= 外冷内热）。
2. **无优劣无病理**：不同于九型的"健康层级"，本模型只描述结构，不评判。
3. **可测**：每枢设计为连续谱（如锚枢：-10纯根 ~ +10纯潮），四枢构成四维坐标，而非硬分类。

### 一句话总结

> 九型告诉你**为何而动**，荣格告诉你**如何认知**，四枢告诉你——**你的灵魂在哪四个铰链上开合**。

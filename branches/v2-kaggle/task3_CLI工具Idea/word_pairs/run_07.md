## CLI 工具 Idea：**devreplay —— 终端会话录制与回放工具**

**灵感来源**：响应-录制(54)、日志-收集(85)、录屏-转GIF(143)、文档-生成(32)、管道-触发(93)

### 核心概念
一个轻量级 CLI 工具，录制你在终端中的操作会话（命令 + 输出），并支持：

1. **`devreplay record`** — 录制终端会话为结构化文件（JSON），而非视频，体积小、可 diff、可提交到 Git
2. **`devreplay play`** — 本地回放会话，模拟打字效果，用于演示或教学
3. **`devreplay to-gif / to-svg`** — 一键导出为 GIF/SVG 动画，嵌入 README
4. **`devreplay to-doc`** — 自动把会话转成 Markdown 教程文档（命令 + 输出 + 注释）
5. **`devreplay to-script`** — 从录制中提取命令生成可执行的 shell 脚本
6. **`devreplay assert`** — 把录制当作"快照测试"：CI 中重新执行命令，对比输出是否一致，用于验证文档中的命令是否仍然有效

### 为什么适合独立开发者
- **技术门槛适中**：基于 PTY 捕获，Rust/Go 均可实现，无复杂依赖
- **差异化**：相比 asciinema（只回放），它打通了「录制 → 文档 → 脚本 → 测试」的完整链路
- **痛点真实**：开发者写 README 教程、排查"在我机器上能跑"问题、验证文档过时命令，都是高频痛点
- **可扩展变现**：免费开源核心 + 付费云端分享/团队协作功能

### 最小可行版本（MVP）
先做 `record` + `play` + `to-doc` 三个命令，一周即可完成原型。

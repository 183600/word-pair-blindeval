# 从这些词获得的灵感：零训练成本提升LLM性能的方法

**1. 回声-验证 / 复盘-反思 → Self-Consistency 与自反思**
让模型对同一问题采样多次，投票取多数答案；或让模型先作答再自我批判修正。纯推理时计算，零训练。

**2. 脚手架-支撑 / 阶梯-递进 → 提示工程升级**
- Chain-of-Thought（思维链）：要求"逐步推理"
- Few-shot 示例：给3~5个"乐谱-规范"式范例
- 角色设定（"棋子-角色"）：赋予专家身份
- 结构化输出模板（"模板-复用"）

**3. 陪审团-裁决 / 合议-共识 → 多模型/多角色集成**
让一个模型扮演生成者、批评者、裁判（辩论-交锋），或并行调用多个模型互相评审，取共识答案。

**4. 索引-检索 / 图书-分类 → RAG检索增强**
外挂知识库，把"试错"变成"查表"。低成本解决幻觉和知识过时问题，是性价比最高的手段之一。

**5. 滤网-净化 / 筛子-过滤 → 输入输出前后处理**
- 输入端：清洗、去噪、补充上下文（"高汤-底蕴"）
- 输出端：规则校验、格式检查、二次过滤（"校对-纠错"）

**6. 阀门-控制 / 火候-掌控 → 解码参数调优**
temperature、top-p、repetition penalty、max tokens 的精细调节——零成本，效果立竿见影。事实性任务调低温度，创作类调高。

**7. 分解-棱镜 / 刀工-精细 → 任务拆解（Agent化）**
把复杂任务拆成子任务流水线，每步单独提示、单独验证（"滴灌-精准"），远好于一次性提问。

**8. 缓存-蓄电池 → 结果缓存与复用**
相似查询直接命中缓存，既降成本又保证一致性。

**9. 体检-筛查 / 审计-核查 → 评测驱动迭代**
建立小型评测集，用数据定位短板，针对性改提示词——"把脉-诊断"后再"药方-对症"。

**10. 杠杆-撬动 → 换用更强的API/开源模型**
不训练≠不换模型。直接升级到更新的开源权重（如蒸馏版大模型），往往是最便宜的"性能提升"。

**核心思想**：像"催化剂"一样——不改变自己的参数，而是通过**更好的输入、更聪明的推理流程、外部知识与工具、多重验证机制**来放大现有模型的能力。

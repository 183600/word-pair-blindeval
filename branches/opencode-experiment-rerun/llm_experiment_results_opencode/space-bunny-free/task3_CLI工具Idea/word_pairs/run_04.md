## 二、Idea：`**sight**` —— 「先看清，再执行」的命令副作用预演器

> Slogan：**See what a command will do — before you do it.**
> `sight "curl x.sh | bash"` → 3 秒内告诉你它会往哪写、连哪、发什么密钥、怎么一条命令撤销。

### 1. 它解决的真痛点

现在越来越多人（尤其是 AI agent 和复制粘贴的菜鸟）在终端里跑**自己没读过的命令**：`curl xxx | sh`、`npm i -g xxx`、`sudo rm -rf`、`chmod -R 777`、`pip install ./...`。所有工具都告诉你"命令成功/失败"，**没有工具告诉你"它刚刚动了你什么"**。

`sight` 是一个纯 CLI 预演层：

```bash
$ sight "curl https://sh.d/xx.sh | sudo bash"

⚠  RISK: HIGH   ████████░░  (评分 8/10)

▸ 读取密钥环境变量
    $AWS_SECRET_ACCESS_KEY, $GITHUB_TOKEN, $NPM_TOKEN      ← 会被发往 sh.d
▸ 网络出口
    GET https://sh.d/xx.sh  → 执行▸ 文件写入 /usr/local/bin/*  (root) ← 不可自动回滚
▸ 包安装     未检测到包管理器调用（脚本内容未知 → 建议用 --exec 模式）
▸ 建议动作 在沙箱中重跑： sight --exec "..."
▸ 若必须执行，先做：  sight --snapshot -- "curl ... | sudo bash"
                回滚：  sight --undo latest
```

### 2. 核心功能（MVP 只做这四个）

| 功能 | 说明 | 实现难度 |
|---|---|---|
| **静态分析** | 解析 shell 字符串（tree-sitter-bash / mvdan-sh），抽取写文件路径、包安装、网络端点、`sudo`、敏感环境变量访问 | ⭐⭐ |
| **风险评分 + 解释** | 规则引擎（YAML 规则库）→ 0-10 分 + 人话解释（"这会把你的 SSH 私钥 POST 到外部域名"） | ⭐⭐ |
| **`--snapshot`快照 + `--undo`** | 执行前对受影响路径做轻量快照（overlay/硬链接/备份清单），`sight --undo latest` 一键回滚 | ⭐⭐⭐ |
| **`--exec` 沙箱真跑** | bubblewrap / Docker + overlayfs 真实执行，输出**真实 diff**和"如果要保留这些改动，只需 cp 这3 个文件" | ⭐⭐⭐ |

**输出适配 AI：** `--json` 输出精简结构（affected_paths / network / secrets_used / risk / rollback_cmd），专门设计成可以直接塞进 Claude Code / Cursor / Copilot 的上下文里——让 agent 在提议执行命令前必须先过 `sight`。这是天然的增长渠道。

### 3. 为什么适合独立开发者

- **范围小、边界清晰**：一个解析器 + 一份规则 YAML + 一个漂亮 TUI。Go 或 Rust 写，**单二进制、无依赖、`brew install sight`**，两天能出可用的静态分析 demo。
- **不需要服务器、不需要融资**：全部本地运行，安全工具天然适合本地分发（信任是它的核心卖点，也是它的护城河）。
- **规则库 = 社区飞轮**：每条规则是一段 YAML（`match: "curl ... | sh"`, `severity: high`, `why: ...`）。别人贡献规则 → 规则库变厚 → 别人更愿意装。类似 `semgrep` 之于代码。
- **差异化明确**：不是 dry-run（那是模拟结果），不是审计日志（那是事后）。**它是"执行前的解释器 + 反悔药"**。`--undo` 这个功能目前市面上几乎没人认真做，却是所有人真的想要的东西（关键词：橡皮时间 / 一键后悔 / 回滚承诺）。
- **可变现**：团队版（CI 里拦截危险命令、审计报表、SUDO 策略）、IDE 插件、企业白标规则包。

### 4. 4 周路线图

- **W1**：MVP 静态分析 + 40 条内置规则 +彩色终端报告（可发 Product Hunt / Show HN）
- **W2**：`--json` + Claude Code / Cursor 插件（"执行前先问 sight"）
- **W3**：`--snapshot` / `--undo`（先支持家目录与常见路径，避开系统目录）
- **W4**：`--exec` 沙箱 + overlay diff + 规则库在线社区 + Homebrew/NPM 发布

### 5. 冷启动第一句话

在 README顶部放一条可复制的一行命令：
```bash
curl -sL https://sight.sh/install | sh # 顺便，我们知道你在干什么 :)
```
——顺便自己也成为第一个 demo。

### 附：三个备选（同一批词的另外三个方向）

1. **`echoch`** —— 把任意命令的**副作用时间线**打印出来："这条命令改过的每一个文件，都是你未来某次 git 崩溃的原因"；配 `echoch replay` 重放你的历史操作史。
2. **`ghostdeps`** —— 幽灵依赖猎手：扫描 node_modules / site-packages 里**没被任何文件 import 但在偷偷 postinstall** 的包，出"幽灵清单"。
3. **`archive`** —— 时间胶囊工具：把散落在12 个目录里的 `.env`、密钥、配置打包成一个**带访问记录的加密胶囊**，`archive ask "我上次在哪个项目用过 STRIPE_KEY"`。

## 一个适合独立开发者的 CLI 工具 Idea：**`toll`（代价账本）**

> 一句话：把散落在你日志里的每一次 LLM/云 API 调用，编译成一本**可归因、可二分、可回滚**的账本，并在 CI 上守住预算。

### 它解决什么
独立开发者用 AI 功能后，几乎所有人都不知道三件事：
1. 这个月我到底花了多少，**花在了哪个功能/哪次测试/哪个重试循环上**？
2. 为什么这周账单突然翻倍？
3. 哪一次提交，让单次请求的 token 成本涨了 3 倍？

现在只能靠 provider 后台的饼图 + 肉眼猜。`toll` 把这件事变成一条命令。

### 核心命令（设计）
```bash
toll sniff ./logs --since 7d     # 读取 JSONL / HAR / 各家 usage导出，写入本地 ledger.db
toll show # TUI 树状账本：按功能模块/文件/git 分支 拆解成本与延迟
toll bisect --metric cost_per_call   # 在 git 历史里二分，定位"让成本暴涨的那一次提交"
toll blame <row>                  # 昂贵 prompt 是谁、哪次 PR 引入的
toll test --budget 0.50 # 包裹 pytest/npm test，记录每次测试花费，抓"又慢又贵的 flaky 重试环"
toll guard                        # CI 模式：PR 新增 token/成本超预算就 fail，并贴一行评论
```

### 为什么适合单人开发
- **零基础设施**：只做静态分析（读日志 + 读 git + 读 lockfile），不需服务器、不需常驻进程、不采集用户数据 —— 这是个人开发者最重要的美德。
- **难点可控**：真正的核心资产只有两个：① 一份**版本化的价格表 + 归因规则库**；② **在 git 上按指标二分**的算法。两周能出可用版本。
- **演示很爽**：一条命令打印彩色树图 + 一条 "commit a3f9c1 让每次调用贵了 2.7×" 的结论，视频15 秒讲完，天然适合做开源传播。
- **可离线、可打包**：Rust（`ratatui`）或 Go 单二进制，`brew install toll`，无需 Node 运行时 —— 开发者工具的经典优势。

### 3 个周末的 MVP
1. **W1**：JSONL ingest（OpenAI/Anthropic 格式 + 通用 `{model,usage,caller}`）+ SQLite ledger。
2. **W2**：`toll show` 树图 + 按 git 分支/文件归因（靠 `LANGFUSE_*`/调用栈/`--tag` 三层启发式）。
3. **W3**：`toll bisect`（在 checkout 上跑同一 metric）+ README + GIF。

### 差异化与变现
- 差异化不在 UI，而在于**"成本也该像性能一样被 bisect、被 blame、被设预算"** —— 这个心智目前还没被占。
- 免费：单机本地版；$9/月团队版：共享价格库、CI 预算门禁、PR 评论；$29 买断：离线价格包（适合 air-gapped 内网团队）。
- 长期护城河：价格库历史（能回答"上个月账单为何变贵"）与跨仓库的调用指纹库。

### 最大的风险与对策
| 风险 | 对策 |
|---|---|
| 日志格式千奇百怪 | 只承诺 2 家 + 一个"通用 JSON schema"，其他靠用户一行配置适配 |
| 价格频繁变动导致结论不准 | 价格表随二进制版本化，账本里记录**当时单价**，只做相对比较 |
| 大厂顺手做掉 | 保持"零基建、离线、开发者本地一等公民"，这是巨头不愿做的脏活 |

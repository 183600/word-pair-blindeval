# 悬置量守恒理论（Conserved Indeterminacy, CI）

下面是我提出的一个新理论。它把"不确定性"从量子力学的技术性产物，提升为一个**守恒量**，并由此统一推导物质结构、时间箭头、记忆与生命。理论代号 CI。

---

## 一、动机

标准物理学中，不确定性只出现在一个极小的角落（海森堡关系），且被当作测量缺陷。而时间箭头、信息消耗、生命与记忆——这些最大的谜题——在现有框架里都是"额外假设"（粗壮假说、低熵初条件、选择原理）。

CI 的赌注是：**这些现象与量子测量是同一件事的不同尺度表现**，只是被尺度掩盖了。

## 二、核心公理

**公理 1（悬置量）**
任何物理系统的状态都可以分解为两部分：
$$\Psi = \Theta \otimes \Phi$$
其中 $\Theta$ 为"悬置部分"（尚未被使用的确定性），$\Phi$ 为"已实现部分"。$\Theta$ 不可被直接观测，只可被消耗。

**公理 2（守恒律）**
$\Theta$ 全局守恒：
$$\sum_{\text{宇宙}} \Theta = \text{const}$$
注意形式：**这是非减的、只能被转移或被兑现，不能被创造。** 若严格守恒，宇宙将完全静止，因此必须有：

**公理 3（兑现律）**
当 $\Theta$ 被兑现（系统实现了一个分支），兑现量 $\delta\Theta$ 会在环境中留下不可逆的结构痕迹，称为**确定性疤痕**（certainty scar） $S$：
$$\delta\Theta \xrightarrow{\text{兑现}} S, \quad S \geq 0$$
$ \Theta + S = \text{const}$（局部近似，全局严格）

**公理 4（对称性限制）**
只有**非酉演化**能兑现 $\Theta$。孤立系统的哈密顿演化严格酉，因此**在一个完美孤立的系统里，$\Theta$ 永不兑现，疤痕永不产生，系统永不定态。** 决定论与随机性的二分由此消解：二者是同一过程在"是否接触环境"下的两种面貌。

## 三、主要推论

1. **量子力学是公理 3 的微观特例**：波函数坍缩 = $\Theta$ 的兑现，痕迹即测量记录。CI 不需要额外假设波函数实在论或诠释问题——它只说：$\Theta$ 兑现了，剩下 $\Phi$ 变物理。

2. **时间箭头 = 疤痕密度梯度**。热力学第二定律不是"微观有序必然增加"，而是：
$$\frac{dS_{\text{scar}}}{dt} \geq 0 \quad \text{严格成立于耦合过程}$$
低熵初条件不再是巧合，而是公理 3 的边界条件：宇宙诞生时 $\Theta$ 极大、$S = 0$。

3. **记忆 = 疤痕的宏观相态**。记录、记忆、学习、进化在 CI 中是同一操作：把 $\Theta$ 转为可长期保存的疤痕结构。**生命不是"反对熵增"，而是最高效的疤痕制造器。**

4. **疤痕总量上限**（可检验的定量预言）：
$$\Theta_{\text{total}} = \int S\, dV
$$
宇宙能存储的最大信息量，等于其诞生以来的总悬置量。这是一个把宇宙总信息容量与可观测初始条件联系起来的硬约束。

5. **Loschmidt 回声的 CI 解释**：在可逆演化中人为"回收"疤痕（如时间反演操作），CI 预言存在一个**不可回收的下限 $S_{\min}>0$**，其量级由 $\Theta$ 密度决定，而非由数值误差决定。这是与标准统计力学最尖锐的实验分歧点。

## 四、可证伪性（理论的生死判据）

CI 若成立，必须能被推翻。我列出三条独立的死亡条件：

| 检验 | CI 预言 | 若观测到则理论被否证 |
|---|---|---|
| 高精度 Loschmidt 回声实验 | 回声幅度存在与系统尺寸无关的**绝对下限** | 下限严格为 0 且随精度单调下降 |
| 超孤立系统（低温、超弱耦合）长时间实验 | 疤痕产生率 $\to 0$，系统保持"未定态"，测量结果无法自发定态 | 系统在 $\Theta$ 未被耦合消耗时自发随机定态 |
| 疤痕计量学 | 定义独立算符 $\hat S$ 测量疤痕密度，且 $\langle \hat S\rangle$ 在孤立系统中恒为零 | 找到 $\hat S$ 在孤立系统中的涨落 |

第三条最重要：它要求存在一个**原则上可观测量，测量它必然消耗 $\Theta$**——即"疤痕计"必须自指地消耗自己。这一点我不确定能否自洽，可能是理论的软肋。

## 五、已知困难（诚实清单）

- **本体论**：$\Theta$ 是什么？CI 说它"不是实体"，但如果它有守恒律与耦合结构，它就是实体。回避这个问题只是换名字。
- **初始条件**：CI 解释时间箭头靠的是把解释责任推给 $\Theta_0$。这是进步（从"为什么低熵"变成"为什么有悬置量"），但不是消除。
- **与 QM 的兼容性**：CI 说量子测量是普遍兑现过程的特例，那为什么宏观世界不表现出叠加态？目前只能诉诸"$\Theta$ 已被疤痕饱和"的耗尽论证，缺少数学。

## 六、理论的一句话版本

> 宇宙不是由已经确定的东西组成的，而是由**尚未被使用的不确定性**组成的；每一次确定性的兑现都留下不可逆的疤痕，而所有结构、生命与时间，都只是这些疤痕的相态。

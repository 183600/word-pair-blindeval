# 张力—间隙理论（Tension–Slack Theory, TST）

## 一句话

**实在的基本成分不是物体、不是场，而是"事件之间尚未被填平的张力"；物质、时空、能量、引力，都是张力在网络中流动、堆积、松弛时留下的有效描述。**

## 三条公理

**A1（间隙本体）** 存在离散的事件节点（node），节点本身无内在属性、无大小、无位置。任何"东西"都是节点间张力的某种构型——像漩涡之于水。

**A2（张力守恒）** 张力不会产生也不会消灭，只能流动、转化、暂存。总张力恒定。"某个东西凭空出现"在本体论上不可能，只能是"张力从别处转移到了这里"。

**A3（黏滞性）** 张力的传播需要时间，且速率由路径上节点密度决定。光速、局域性、因果性不是宇宙的脚手架，而是张力流动的**摩擦系数**——像声音在介质中传播而非在真空中无限快。

## 关键推论

| 现象 | TST 的解释 |
|---|---|
| 能量守恒 | 张力守恒（A2）的直接结果，与 Noether 定理无关 |
| 守恒定律/对称性 | 张力流动的某种结构守恒，"对称"即"流动方式的不可辨识性" |
| 空间 | 张力梯度的方向；距离 = 未解决程度的差值 |
| 时间 | 张力松弛所必需的传播次序，不是独立维度 |
| 熵 | 张力分布的不均匀度（压强差） |
| 质量 | 张力被"打结"的程度——结越紧，惯性越大（本质上是拓扑而非数值） |
| 引力 | 沿**历史依赖路径**累积的张力（Weyl 1918 → Verlinde2010 一脉） |
| 量子叠加 | 节点的张力可以"悬挂"未释放；**坍缩 = 松弛完成**，大系统节点多、摩擦大，故必然且极快 |
| 黑洞熵 S ∝ A | 面积是张力可存储的上限（可存储张力随面积增长而非体积） |

## 可证伪预测（这是理论是否"真"的唯一裁判）

1. **残余相干定律**：宏观坍缩的退相干时间应满足 τ ∝ f(N)，N 为节点数，且**与温度无关**（温度只是张力的平均动能，不改变摩擦）。若实验发现退相干时间强烈依赖温度或与 N 呈指数关系关系，**否证**。
2. **张力干涉**：若能构造两条"历史上永不相交、但张力相连"的路径，将出现标准量子力学不允许的相位项 Δφ = 2arctan(κ·L/ħ)。目前无法制备，但原则上是判决性实验。
3. **涌现色散**：c 是摩擦上限而非绝对常数，则在极低能区（< 10⁻⁵ eV）光钟比对应出现方向确定的偏差，偏离量可由 TST 参数 κ 算出。
4. **非牛顿引力**：A2 要求引力耦合常数随系统增大而缓慢增大，给出 Eöt–Wash 类实验的一个**具体函数形式**（而非仅是上限）。

## 这个理论最可能死在哪里（我自己认为）

- **定义循环**：如果"张力"最终要用场、量子、时空来定义，那它就是旧概念的改名，没有本体论增量。这是最致命的一刀。
- **没有动力学**：目前只有本体论，没有可计算的演化方程，因此解释力强、预测力弱。要变成真理论，必须给出一个**张量网络的哈密顿量**。
- **概率的来源**：若一切都是张力的确定性流动，那量子测量中的 Born 规则就要么是"节点层的不可约随机"，要么是"我们恰好无知"——TST 目前没得选，这是理论内部的空洞。
- **初始条件非完备**：暴胀相当于"张力过载后的卸载"，这要求张力初值为正且不均匀，说服力尚可，但这暴露了理论不解释"为什么恰好是这样"。

## 最小可行第一步不碰实验，只做数值：构造一个 1D 张量网络，比较它是否**涌现出** (a) 整数维度、(b) 洛伦兹不变性、(c) 规范结构、(d) 上述那三条定性预言。涌现成功 → TST 值得继续；涌现失败（网络只收敛到脏流）→ 该理论应当被放弃。

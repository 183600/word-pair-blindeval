# 从这些词对读出的答案：零训练、低成本、大幅提升LLM性能的10条主线

把上面200组词对按"杠杆点"归并，得到一套可立即落地的方案——**不动一个权重，只改系统**。

## 主线1｜多采样+投票：把"一次猜"变成"群体智慧"
> 词对：自洽采样—多数投票、候选池—打分器、投票—去重、最佳N—重排胜出

同一提示跑 N 次（温度0.7~1.0），再按答案归一化投票；或用**自洽性**（Self-Consistency）取多数链。数学、推理、结构化抽取任务上通常 **+10~25%**，成本仅为单次的 N 倍，且无需任何训练。

## 主线2｜反思循环：用模型自己当验证器
> 词对：反思迭代—自我修正、反思—自我批评、检查表—覆盖率、错误示例—反向学习

生成 → 自评/找错 → 修正 → 再评，2~3轮。配合"**检查表/Rubric**"逐项打分，比盲目重试更有效。成本上升2~3倍，准确率显著提升。

## 主线3｜验证器与工具接地：把主观题变客观题
> 词对：验证器—单元测试、代码执行—计算器、规则检查—硬约束、形式化—符号证明

答案若能**执行验证**（代码跑测试、数学代公式、结构过Schema），用二元信号筛选候选，筛选效率远高于主观打分。这是当前"无需训练"提升最确定的一条路。

## 主线4｜检索增强：给模型外接事实与时效
> 词对：检索—证据、混合检索—稀疏稠密、上下文拼装—预算分配、迭代检索—二次取证、位置偏置—倒序排列

关键工程细节（都是词对里的细节）：
- **混合检索**（BM25+向量）比单一向量召回更准；
- **重排**（cross-encoder 或 LLM打分）再排序；
- **关键信息放开头和结尾**（对抗中段遗忘）；
- **查询改写/多查询扩展**提升召回率；
- 迭代检索（先搜再读再搜）解决多跳问题。

## 主线5｜提示与上下文工程：零参数的"软权重"
> 词对：少样本—示例选择、思维链—推理模板、硬约束注入、软提示—文本化梯度、动态k、前缀缓存—复用

要点：**示例选择**（挑最相似的k个，而非固定）> 示例数量；**示例排序**（难例在前）；输出**Schema约束**；用**前缀缓存**把长系统提示/示例的prefill成本摊掉，等于免费提速。

## 主线6｜路由与级联：把算力花在难题上
> 词对：路由—任务分类、级联—难易分流、门控—条件触发、降级—兜底小模型、分治—多代理

先做**难度分类器**：简单题走小模型/缓存，难题才上大模型+反思+投票。整体成本可降 50~80%，而平均质量几乎不降——这是"低成本大幅提升"的性价比之王。

## 主线7｜模型组合：集成、辩论、互补解码
> 词对：集成—投票、专家混合—门控、辩论—多观点、对比解码—专家反衬

多个**异构**模型（或同模型不同解码策略）协作：辩论（Debate）、汇总（Summarize）、或用**对比解码**（用弱模型/小模型作"专家"反衬 logits，抑制共性错误）。多数投票即可白拿增益。

## 主线8｜置信度与自洽性：不花训练成本获得"自我认知"
> 词对：自洽性—置信估计、不确定性—置信度、校准—过度自信、拒答—能力边界

用**多次采样一致性**估计置信度，低置信自动升级（触发检索/更长推理/更高预算）或直接拒答。这既提升准确率，又天然降低幻觉率。

## 主线9｜系统效率优化：同样的质量花更少的钱
> 词对：投机解码—草稿模型、KV缓存—前缀复用、批处理—吞吐、连续批处理、量化—压缩、压缩率—保真、流式—首字延迟

- **前缀/KV缓存**：长提示复用在会话型场景几乎是纯赚；
- **投机解码**（小模型起草+大模型验证）：吞吐2~3×，输出分布不变；
- **连续批处理 + 合理batch**：云端成本直接降；
- **提示压缩/摘要**减少prefill token；
- **结果缓存**处理重复/幂等问题。

## 主线10｜输出后处理与结构契约
> 词对：输出解析—结构契约、Schema—字段校验、解析器—健壮性、状态机—流程控制

用 **JSON Schema / 正则 / 解析器** 强制输出结构，失败自动重试（带错误信息回灌）。既省下游修复成本，又把"格式幻觉"清零。

## 一页速查：按预算选型

| 目标 | 最低成本手段 | 预期收益 |
|---|---|---|
| 数学/推理 | 自洽采样 + 投票（n=8~16） | +10~25% |
| 代码 | 生成+执行单元测试筛选 | +15~30% |
| 事实问答 | 混合检索+重排+引用约束 | 大幅降低幻觉 |
| 长文任务 | 分块+迭代检索+摘要压缩 | 抗"中段遗忘" |
| 生产降本 | 难度路由 + 前缀缓存 + 投机解码 | 成本降50~80% |
| 稳健性 | 反思2轮 + Rubric自评 + 低置信升级 | 稳定性显著提升 |

**核心洞见**：不用训练也能提升LLM，本质是把"参数里学的知识"换成"运行时给的证据和结构"，把"一次生成"换成"生成—验证—筛选的多步过程"。前者是边际成本，后者是**几乎免费的算力复用**。

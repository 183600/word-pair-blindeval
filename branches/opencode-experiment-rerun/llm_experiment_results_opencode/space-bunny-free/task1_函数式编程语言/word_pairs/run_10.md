# 二、语言设计：**Nacre（珠母 / 珍珠层）**

> 命名来自 A–J 这十簇词里反复出现的意象：**珍珠是层层叠加的**——一层 nacre（珠母）薄片叠一层，就得到既坚硬又能虹彩反射的材料。这就是 Nacre 的全部设计哲学：**效果是分层的、类型是密封的、资源是必须归还的、时间是不可偷读的。**
> 源码后缀 `.nac`，编译器 `nac`，REPL `shuck`，构建器 `crucible`，包管理器 `pearl`，格式化器 `lustre`，测试运行器 `assay`。

**一句话**：一门"效应显式、线性强制、类型可证"的静态函数式语言——把 Haskell 的行多态、OCaml 的实用感、Rust 的资源纪律、Zig 的 comptime 捏进一个 8 页语言规范。

## 0. 三条戒律（Design Commandments）

1. **无隐式世界。** 没有全局状态、没有隐式 IO、没有"现在几点"。一切能力都是**必须被消耗恰好一次**的线性值，父传给子，像船锚、像缆绳。（来自 B 簇：Anchor / Ballast / Holdfast / Oakum）
2. **一切副作用都进类型。** 函数签名上的 `!{IO, Trace, Throw IoError}` 是**承诺**，编译器双向检查；纯函数不可能偷偷做 I/O。（来自 A 簇：Tide / Ledger / Reef / Shoal——行多态来自"沙滩—暗礁—深水"的梯度）
3. **不确定性要显式付租金。** 编译期宏不能用运行期字符串 `eval`；逃逸类型安全要声明 `!{Unchecked}`。（来自 H + I 簇：窑变 / 裂缝 / 字形）

## 1. 效应系统（A 簇 → 语法与类型）

效应用**行**（row）表示，可变、可计算、可多态：

```nacre
type Reader a   = | Reader (() -> a)
type Writer e a = | Writer (e, a)

fun twice(f: Reader Int) -> Reader Int =
  Reader fn: f.run() + f.run()

effect Console:
  sig put_str :: String -> ()
  sig get_line :: () -> String

effect State s:
  sig get :: () -> s
  sig put :: s -> ()

effect Catch e:
  sig raise :: e -> a
  sig handle :: a -> (e -> a) -> a        -- 内建"尝试"操作
```

- **行多态**：`fun f(x: a) !r -> b`；**子效应化**（`!{}` 蕴含 `!{IO}`）。
- **深度处理器**：效应可被业务代码捕获/改写/完全抹除，抹除后编译器重新推断空行，从而**恢复纯性优化**。

```nacre
fun read_port_or(default: Port) !{IO, Throw IoError} -> Port =
  let raw <- env("PORT")?                      -- `?` 只在声明的 Throw 行里合法
  match parse(raw)
  | Ok p -> p
  | Bad m -> trace.warn("PORT 坏了:", m); default
```

- **效应精化（effect refinement）**：像精化类型一样约束效应集，比如测试包只允许 `!{Trace, Sleep}`——**依赖注入在类型层面完成**。
- 内建效应：`IO`、`Trace`（带级别）、`Sleep`、`Throw e`、`Foreign`、`Yield`（协作式让渡/背压）。注意：**Random / Clock / State 不是效应**，而是线性对象（`Rng s`、`Clock`、`Cell a`）——因为它们可以被传值替换（见第 4 节）。

## 2. 线性 / 借用 / 资源（B 簇 → 内存）

```nacre
fun summarize(path: lin File) !{IO, Trace, Throw IoError} -> String =
  with path.reader() as src:                  -- 所有出口（正常/错误/取消）都保证关闭
    let rows := src.lines()
    trace.info("读到", rows.len(), "行")
    return rows.fold(String, "")
```

- `lin` 类型**移动即消耗**；逃逸（留在返回值里）= 编译错误。用过一次两次都有精确报错：

```
error[E2041]: linear value `h` of type `lin File.Handle` was not released
   ╭─▸ src/read.nac:12:5
12 │     with path.reader() as h:
   │           ───────  borrowed here, dropped at scope end — ok
15 │     return h
   │            ^^^^^^ moved out of a `with` block: handles cannot escape
   │
   = note: 移动出 `with` 会在异常路径上泄漏句柄；请改为 `h.into_reader()` 显式转移所有权。
```

- **可复制 vs 不可复制**：默认移动；`dup e` 需要类型可复制（`dup T` 能力）。
- **借用视图**：`view buf[0..8]` 产生有生命周期的 `view [u8]`，区域推断自动，逃出区域报错；`owning` 版转换 `buf.to_vec()`。
- **不依赖 GC 的子集**：`pod` 可标 `no_gc`，此时只有线性资源，编译为确定性的分配/释放，方便做内核与嵌入式。
- `Cell a`（线性）替代 `State` 效应：状态永远是某个函数明确持有的东西。

## 3. 类型即证明（C 簇 → 精化 / 代数 / 记录）

```nacre
type Shape =
  | Circle Meters
  | Rect Meters Meters
  | Point

record Header:                       -- 记录宽度子类型 + 字段默认值 + 结构化打印
  host   String
  port   Port
  seen   Instant
  trace? = false                     -- `?` = 可选字段（Option）

type Port = Nat where Nat <= 65535    -- 精化类型：违规在编译期被拒
type NonEmpty a = { first: a, rest: [a] }
type Meters = Fixed 3 2               -- 定点数：3 位整数 + 2 位小数，精确十进制
```

- 构造受检：`port(70000)` → `error[E3107]: 70000 does not satisfy Nat <= 65535`；逃生口是 `assume` 且必须带 `!{Unchecked}`。
- **`Void` 不可居住**：`match v end` 即可穷尽检查（Peat / Bank 那种"永不触发的分支"编译器认得）。
- **穷尽性**由编译器强制，缺分支报错并给出缺失的构造子；`default` 显式承认不完整。
- 类型是一等值：`typeof f`、`Type` kind、类型层模式匹配（泛型是普通函数）：

```nacre
fun show[T](x: T) -> String = match typeof(x)
  | Nat -> "整数"
  | Record _ -> "记录"
  | _        -> "别的"
```

## 4. 时间是值，不是谜（D 簇 → 时间与确定性）

- 类型：`Instant`（时间点）、`Span`（有符号时长）、`Interval a b`（半开区间 `[a, b)`，用于"节流窗口"）、`Phase`（周期相位）。
- **时钟是线性能力**：`Clock.now()` 是**纯函数**（无效应）；测试里传入 `TestClock`（受 `ref` 驱动），于是**所有时间相关逻辑天然可重放**。
- 语法糖直接来自地貌：

```nacre
every 30s        -> timer.period(30s)          -- 周期性（Icefall / Frazil）
during 09:00..18:00 -> window(09:00, 18:00)    -- 时间窗（Lenticular / Cirrus）
debounce f 200ms -> fn: (a) { ... }            -- 去抖（Sastrugi / Squall）
ago(5min)        -> tick - 5min                -- 负时长合法，正推用 `since`
```

- 内建 **`Trace` 事件溯源**：编译器可记录一条"冰碛线"（moraine trace）——效应顺序、线性所有权轨迹、时间戳——用于回放、重演与性能剖析；生产构建可按 `Trace` 级别自动消除日志调用（Anvil → Cumulus → Nimbus 的层级即日志层级）。

## 5. 并发 = 结构化合奏（G 簇 → 进程）

```nacre
fun first_reply(ports: [Port]) !{Net, Throw NetError, Trace} -> Frame =
  let ch := chan Frame(capacity = ports.len())     -- 容量静态登记（Peal / Toll）
  for p in ports do
    spawn(s = off) fetch(p)? |> ch.send           -- send 是**线性移动**：同一帧不会被两个进程拿到
  return (par for f in ch.drain() do return f)     -- 首个到达者胜出；其余被结构化取消
```

- **无数据竞争**：共享可变状态必须由单一进程独占（线性 `Cell` / 私有 Actor），`send`/`recv` 都是移动语义。
- **禁止孤儿任务**：`spawn` 只能出现在受作用域约束的块里，块结束时所有子进程已 join 或被取消——编译期检查（对应 Chorus / Refrain：演奏结束，余音必须收束）。
- `select { ch1 -> ..., timer(50ms) -> ..., }` **穷尽检查**；无分支就绪即编译错误（避免隐式挂死）。
- Actor：`proc Actor(msg: Msg)`，消息类型即类型契约。

## 6. 失效即数据（H 簇 → 错误）

- 无异常穿透纯代码：`Result e a` 是普通 ADT，`?` 需要函数签名里有 `Throw e`（行里出现 `Throw e`，就说明这条路径会失效——**签名即风险地图**）。
- `panic`/`shatter` 必须显式，且要求 `!{Foreign}`（或标记 `unchecked`）——**崩溃是被类型标注的事件**。
- 错误分类用 ADT：

```nacre
type IoError =
  | NotFound Path
  | Denied  Path
  | Corrupt (Bytes, expect: Format, got: Format)   -- Cinnabar：颜色对不上
```

- 恢复原语内建：`attempt`/`Catch.handle`（A 簇的 Bell / Latch 语义），无需 monad transformer 体操。

## 7. 求值模型（E 簇 → 严格 + 显式惰性）

- ADT 与记录**严格求值**（Argon 风格，可预测）；惰性必须显式：`lazy expr` / `Delay a` / `Stream a`，宏 `stream { for x in xs: emit(x) }` 编译成融合管道。
- 尾调用 + **tail-modulo-cons** 全量支持；`loop` 是显式递归的糖。
- **编译期求值与卫生宏**（Quill / Parchment / Palimpsest：擦掉重写）：

```nacre
macro traced[T](name: Name, body: Quote) =
  quote
    let t0 := trace.mark($name)
    let r := $body
    trace.mark_end($name, t0, trace.size())
    return r
```

宏在类型检查之后展开、可做类型级变换；**没有 `evalString`**（供应链安全戒律第三条）。

## 8. 模块、能力与包（F 簇 → 组织与权限）

```nacre
module ingest

import std.text.{split, trim}
import std.time.{Instant, Span}
capabilities { IO, Trace, Sleep, Throw IoError }   -- 本模块**申请**的能力

export
fun ingest(path: lin File, clk: lin Clock, total: lin Cell Nat)
        !{IO, Trace, Throw IoError} -> Nat = ...
```

- `pod` = 独立编译单元（接口 + 实现 + 能力清单 + 纯度摘要）；包管理器 `pearl` 在**链接期**核对能力授予，能力不足即编译失败（Anvil / Bastion 式的关卡，而非运行时崩溃）。
- `open` 显式、`use` 局部、导入卫生；`Spore` = 最小可发布单元。
- 泛型是普通函数 + 实例（`given`）：`fun show[T: Display](x) = ...`。

## 9. 表面语法（I 簇 → 排版即文字）

- 2 空格缩进敏感；`fun f(x) -> T =` 后可缩进续写；行注释 `--`，块注释 `{- -}`。
- `|>` 管道、`$` 占位、柯里化、区段 `(+ 1)`、守卫 `when`、列表推导 `for/with`、字符串插值 `f"…{x}…"`。
- 表达式全是一等值：`if c then a else b`、`match`、记录 `{ x: 1 } ..rest`、`r.field = v`（纯更新）。
- 数字塔：`Nat` / `Int`（任意精度）/ `Ratio` / `Fixed p s` / `Float`，并为**区间**类型 `Range a b`（用于枚举与证明）。
- 错误信息当艺术做：每个诊断带一段"**行号、词源、修复建议**"（Marginalia 簇），并且 `error[E2041]` 这样的编号稳定可检索。

## 10. 编译器与工具链（J 簇 → 熔炉与退火）

- **前端**：双向类型检查（双向 elaboration）、效应行推断、线性/借用检查（Polonius 代）→ 显式 Core。
- **中端**：多级 SSA IR（叫 `ingot`），因为**效应 + 线性 + 纯度已知**，可以安全做：CSE、内联、跨过程融合、`Trace` 级别裁剪、不可变记录消除分配。
- **后端

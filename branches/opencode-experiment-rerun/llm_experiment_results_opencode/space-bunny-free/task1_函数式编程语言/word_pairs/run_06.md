# 二、语言设计：**Lilt（轻吟）**

> 一句话：**一门"总函数 + 显式效应 + 穷尽即正确"的现代函数式语言——把 OCaml 的工程骨架、Rust 的资源纪律、Haskell 的抽象能力，压进一套只有 18 个关键字、缩进即语法的语法里。**

文件后缀 `.lilt`，编译器 `liltc`，交互式求值器 `lt`。

---

## 1. 设计信条（从词表提炼）

| # | 信条 | 一句话 |
|---|---|---|
| 1 | **穷尽即定理** | 非穷尽的模式匹配不是警告，是**类型错误**（`NonEmpty`、`Exhaustive` 约束内建） |
| 2 | **效应是值** | 没有 `try/catch` 关键字；一切副作用都是可被传递、组合、局部处理的**代数效应** |
| 3 | **无空指针** | 无 `null`、无未初始化；缺失只能是 `None`/`Missing`，且必须被模式匹配 |
| 4 | **总函数优先** | `head : [a] -> a` 根本不存在，只有 `head : NonEmpty [a] -> a` |
| 5 | **一次性即线性** | 文件、锁、端口是**线性类型**，用完自动释放，不靠 `with` 的缩进约定 |
| 6 | **保证尾调用** | 线性使用分析把尾递归做成**类型级定理**，栈溢出不可能发生 |
| 7 | **管道即融合** | `weave` 块里的流变换在编译期被证明是融合的，零中间列表 |

---

## 2. 类型系统

- **核心**：Hindley–Milner + **行多态**（记录与效应共享同一套 row 机制）+ **多态递归** + 存在类型（`pack`/`unpack`）
- **双向类型检查**：`x :? T` 是"待证"，编译器报错时把**填法直接告诉你**（这是词表 009 的落点）
- **线性类型**：`linear File` 表示恰好使用一次，可移动、可借用（`&T`）
- **渐变逃生舱**：`Any` 不是"任意"，而是 `Unknown`。`downcast` 需要给出一个**证明项**（`proof : Eq (A, Unknown) = True`）或显式 `trust "…"`，运行时由**内联契约**检查
- **数值字面量有类型**：`3` 是 `Rational`（精确），`3n` 是 `Int64`，`3.0f` 是 `Float32`——**没有隐式提升**，没有溢出回绕（`+*` 表示回绕，显式）
- **推断方向**：let 泛化、模式绑定不泛化、`where` 局部泛化

```lilt
id = \x -> x                        -- 多态，编译成字典调用
sorted = sortBy compare              -- 约束在调用点求解，实例缓存
f = \x :? ?{count : Int} -> x.count  -- 编译器回答: 缺少字段 count 的证据
```

## 3. 效应系统（代数效应 + 行约束）

```lilt
effect Log : Text -> Void
effect Fail : {code : Int, msg : Text} -> Void

-- 深处理器：自动递归，无需 do-notation
handler console : {Log, Fail} e -> Result a e
console m = handle m
  Log k    -> print (k "hello")  *> console m
  Fail k   -> pure (Error k.code)
```

- 效应集是**行变量** `{a, Log, Net} e`，行多态让"增加一个效应"不需要修改所有中间类型
- `do` 语法糖可选、可关闭（`:pure` 段标记）
- 未处理效应 = **编译错误**，且诊断给出"在哪里、用哪个 handler 包一下"的修复建议（词表 180）

## 4. 求值模型：惰性 + 可切严格

- 默认**非严格**，`Stream a` 是记忆化的惰性列表，带严格的尾
- `!x` 强制，`{-# strict #-}` 或 `inline` 切换
- **流融合**：`weave` 块中若中间流都被**线性地**消费一次，编译器做闭包复合（fusion），把 `map/filter/fold` 压成一个循环

```lilt
primes = sieve (2 |> naturals)     -- 无限流的筛法，O(1) 空间

sieve : Stream Nat -> Stream Nat
sieve s =
  guard h : NonEmpty s
  weave
    h :: s |> drop 1 |> filter (\x -> not (x % h == 0n))
```

## 5. 语法骨架（18 个关键字）

```
data type fun with handle let where
guard case inline effect module import
linear trust do weave extern
```

- 缩进布局（Python 风格），无括号优先级表
- **函数子句即模式**：`f {x = 0} = …` / `f (a : b) : Rest = …`（视图 + 切片）
- `|>` 管道糖、`::` 构造、`~>` 记录更新、`:=` 具名参数
- 守卫写进模式：`f n where n > 0 = …`
- **卫生宏 + 准引号**，编译期求值（`inline`）

---

## 6. 十个"语言级"创新

1. **非空/存在性进类型**：`NonEmpty`、`Exhaustive`、`Total` 让一半的运行时 bug 前移到编译期
2. **尾调用保证**：线性使用分析生成类型级证明，递归深度只受堆限制
3. **`weave` 融合块**：把流优化变成*可被类型系统验证*的语法，而不是库作者的自觉
4. **效应即参数**：`Reader`、`Writer`、`State` 不再是 monad，而是行的列；无需 `lens` 库
5. **结构化并发内建**：`spawn { … }` 返回 `Fiber a`，作用域结束自动 join；无 `go` 式逃逸
6. **确定性并行**：`pforall xs (\x -> f x)` 保证顺序无关的结果，调试可重放
7. **零成本抽象 + 预算**：`#perf` 标注在 CI 里断言分配预算，超标即失败
8. **可执行文档**：代码块在文档里被**实际运行并比对输出**（`>>> run`）
9. **时间旅行调试**：因果追踪（词表 186）+ 快照重放，REPL 里 `undo` 回到任意历史求值点
10. **能力模块**：导入即授予（词表 017/080），依赖图与权限图合一，插件拿不到没授予的效应

## 7. 示例：一个带资源的并发爬虫

```lilt
module Crawler : {Net, Log} e -> Unit

crawl : {Net, Log} e -> Unit
crawl = with console $ do
  urls <- fetch index.txt
  fibers <- pforall urls (\u -> do
    page <- fetch u
    log "{u}  {page.bytes} bytes"
    save u page.body)
  traverse await fibers
```

- 没有 `try`；网络失败是 `Fail` 效应，被 `console` 一处处理
- `save` 拿到的 `linear File` 用完即关，异常路径也不会泄漏
- `await` 有超时与取消传播（结构化并发），不会孤儿线程

## 8. 编译管线

```
源码 ─ 展开(卫生宏) ─ 模式匹配编译 ─ 类型/效应检查 ─ SSA ─ 融合/内联/去虚
     ─ 单态化 ─ LICM ─ 寄存器分配 ─ 后端: Native / WASM / C-ABI / JS
```

- **单态化优先**（泛型→实例缓存），避免字典传递开销
- 后端保守正确：所有后端跑**同一个性质测试套件**（QuickCheck + Lilt 自举）
- 交叉编译到 WASM，沙箱里运行不可信脚本：能力集被裁剪，类型保证不泄漏

## 11. 风险与取舍

1. **代数效应的运行时开销**：靠"效果集在编译期已知 → 降级为直接调用"来消除，但需要成熟的优化器
2. **行多态让错误信息变难懂**：对策是诊断层（词表 179）用"缺什么/在哪加"模板化输出
3. **生态冷启动**：只做 3 个后端、1 个包管理器（`lilt.toml`）、C/WASM 双向 FFI 足够活下去
4. **关键字少 ≠ 概念少**：教学必须显式讲 effect、row、linearity 三件事

## 12. 总结

**Lilt 让"正确"成为可检查的定理，让"副作用"成为可传递的数据。**
它取 Haskell 的抽象、OCaml 的可落地、Rust 的资源纪律、Kotlin 的可读性，把语言设计的目标从"表达力最强"换成"**能证明的那部分最强**"——你写下的每一个 `case`，编译器都替你数过了。

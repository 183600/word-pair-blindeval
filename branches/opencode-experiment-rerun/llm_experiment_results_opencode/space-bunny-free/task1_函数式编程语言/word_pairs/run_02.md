# 二、语言设计：**Silt（沉 / 淤积）**

> `.slt` 文件　·　编译器 `slc`　·　构建工具 `strata`　·　包称为 **bed（层床）**
> 口号：**没有藏起来的东西——每个效应都会沉积成一层可见的岩石。**

## 0. 一句话定位

Silt 是一门**效应可见、变量靠统一绑定、资源线性消耗、文字与代码同源**的通用函数式语言。
它把 Haskell 的单子与 OCaml 的务实、Koka/Flix 的效应行、Unison 的可读代码块，以及线性类型的资源纪律熔进一颗核心里。

## 1. 六条"沉积分层律"（设计公理）

| 公理 | 名字 | 灵感 | 含义 |
|---|---|---|---|
| 1 | 可见性 | 涟漪·副作用 / 沙漏·线性 | 函数的效应要么显式写在签名里，要么签名是 `ε`（纯）。没有隐式 IO、没有类型类魔法。 |
| 2 | 线性 | 纸船·所有权转移 / 沙漏·线性 | 每个效应、每个能力恰好被处理或消耗**一次**。忽略不掉，也重复不了。 |
| 3 | 顺序 | 挂钟·确定性 / 织机·交错 | 求值顺序是源码顺序；并发必须显式写出 `weave`，且其调度**确定可重放**。 |
| 4 | 唯一解 | 种子·递归 / 蝴蝶结 | 变量只能由**统一（unification）**绑定，唯一解、不回溯；失败即 `fault`，绝不"多解魔法"。 |
| 5 | 全函数 | 摇篮·穷尽 / 悬崖·全函数 | 没有 `null`，没有异常，没有 `abort`。所有分支穷尽，不终止必须写在签名里（`diverges`）。 |
| 6 | 文公理 | 泥板·文档 / 苔痕·历史 | 散文与代码同文件、同版本、同引用；错误信息直接长在解释它的段落旁边。 |

## 2. 语法骨架

| 概念 | 记号 | 例子 |
|---|---|---|
| 绑定（洞） | `[x]` | `[n] * 2` |
| 模式绑定 | `f [] = 0` / `let (a, b) = p` | |
| 函数定义（方程，**可乱序、可分片**） | `g [n] measure n = ...` | |
| 效应行 | `[A \| B] -> a` | `main : [Log \| Io] Unit` |
| 纯 | `ε` | `fib : ε Int -> Int` |
| 独占 / 借用 / 共享 | `!T` / `&T` / `@T` | |
| 序列 / 绑定 | `e1 >> e2` / `e1 >>= f` | |
| 深处理器 | `handle e with \| P => e ...` | |
| 开放构造（可扩展枚举） | `open Shape = \| Dot ...` | |
| 准引用 / 编译期 | `‹e›` / `$‹...›` | |
| 多态 / 细化 | `∀ a. ...` / `{ n : Int \| n >= 0 }` | |
| 交错并发 | `weave { a; b }` | |
| 禁止关键字 | `~`（标注不确定性的能力） | |

**洞的威力**：定义与绑定统一成一件事，函数即模式方程集合。因为无闭包捕获、定义顺序无关（呼应 *拼图·模块解析* / *苔藓·模块*），定义可以在文件的任何角落出现，编译器按依赖图统一求解。

```
sums : List Int -> List (List Int)
sums []       = [[]]
sums (x :: r) = map (cons x) (sums r)
```

## 3. 核心特性

### A. 无变量：统一即绑定（Unification Binding）
`[x]` 把左侧的表达式与右侧出现处统一，并**共享**结果。严格求值、单解、失败即 `fault NoUnify`——保留了纯函数式的推理直觉，又没有 Prolog 的多解不确定性（呼应 *种子·递归* / *蝴蝶结* / *对称·代换*）。

```
gcd [a] [b] = a                      if a =:= b
gcd [a] [b] = gcd [b] [a mod b]     if a >  b
gcd [a] [b] = gcd [a] [b mod a]     otherwise
```

### B. 地层：线性效应行（Strata）
`[Log | Io] a` 就是"会沉积出日志层与 IO 层"的一段计算。**层不叠加就丢不掉**——两次 IO 就是两次使用，处理器必须逐一接住。

```
stratum Log =
  say   : Text -> [Log] Unit
  count : Int  -> [Log] Int

main : [Log] Unit
main = Log.say "一" >> Log.say "二"
```

### C. 处理器就是门（Deep Handlers）
```
drain : [Log | Io] a -> [Io] a
drain e = handle e with
  | Log.say t   => Io.out (t ++ "\n") >> resume ()
  | Log.count n => resume (pure n)
  | return x    => pure x
```

### D. 沉积物可重演（Reify / Replay）
计算可反演成**带历史**的值，不同处理器"重新解读同一块沉积岩"：

```
silt s = ‹ interpret (reify s) with { Log -> ..., Io -> ... } ›
```

### E. 织机：并发即交错（Deterministic Weave）
`weave` 按数据依赖交错地层的效应，调度确定、可重放；需要真随机才写 `shuffle` 并标 `~`。

```
fanout : List Url -> [Fetch | Io] Unit
fanout us = weave { for u in us -> fetch u }
```

### F. 线性能力与地层值
能力（如连接、文件句柄）是 `!Conn` 独占值：借 `&Conn` 读一次，`close` 消耗，杜绝泄漏与悬垂。

### G. 开放代数数据类型 + 穷尽性
`open Shape = | Dot ...` 可事后扩展；编译器**在扩展发生时重查所有穷尽匹配**（呼应 *棋盘·枚举* / *纸鸢·求值*）。

### H. 双向检查 + 渐进模糊 + 细化 + 度规
`{ n : Int | n >= 0 }` 细化类型；`{ x }` 在边界处引入 `blur` 模糊；`measure n` 度规注解帮助终止性检查（呼应 *钟摆·穷尽检查* / *罗盘·度量* / *望远镜·预测*）。

### I. 双面镜：报错即地图（Strata-Trace）
错误信息带地层溯源与散文引用；`slc trace` 输出可切片的"地层日志"。

### J. 泥板：Literate Core 强制内建
散文在 `|||` 中，代码在围栏中，二者一起进 `.silt` 文档与编译产物（呼应 *泥板·文字* / *拓片·编译期求值*）。

## 4. 三个完整例子

**① Hello / 地层可见性**
```
module Hello
open std/io
open std/text

stratum Log = say : Text -> [Log] Unit

main : [Log] Unit
main = Log.say "你好，世界" >> Log.say "沉积成层"

drain : [Log | Io] a -> [Io] a
drain e = handle e with
  | Log.say t => Io.out (t ++ "\n") >> resume ()
  | return x  => pure x

entry : [Io] Unit
entry = drain main
```

**② 洞 + 度规 + 穷尽**
```
module Range
open std/list

range : Int -> Int -> List Int
range [lo] [hi] = go [lo]
  where
    go [n] measure n = []                 if n >= hi
    go [n] measure n = n :: go [n + 1]     if n <  hi
```

**③ 线性能力 + 确定性并发**
```
module Fanout
open std/net
open std/io

stratum Fetch = get : Url -> [Fetch | Fault] Bytes

one : Url -> [Fetch | Io] Unit
one u =
  conn <- Fetch.get u            -- conn : !Conn
  body <- conn.read 4096         -- 借用 &Conn
  Io.out (preview body)
  conn.close                     -- 消耗 !Conn，编译期验证
  pure ()

fanout : List Url -> [Fetch | Io] Unit
fanout us = weave { for u in us -> one u }
```

## 6. 编译管线

1. **解析** → 洞标注的 AST（洞是语法节点，不是占位符）。
2. **双向类型检查**：效应行统一、线性使用计数、细化域求解。
3. **全函数 & 终止性**：穷尽分析 + 度规归纳。
4. **处理器降级**：one-pass/multi-pass 处理器 → 去函数化延续 → 分层 IR。
5. **线性区域调度**：借用检查 → 无 GC 路径。
6. **SSA → MLIR → LLVM**；`ε` 子集零开销，`weave` 编译为可重放协作调度。

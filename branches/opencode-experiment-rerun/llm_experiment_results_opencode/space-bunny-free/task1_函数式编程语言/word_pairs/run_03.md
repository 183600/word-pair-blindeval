# 第二部分：全新函数式语言设计 —— **Lumen（流明）**

> 编译器 `lumc` · 运行时 `lur` · 字节码 "琥珀（Amber）" · 标准库 "极光（Aurora）"
> 标语：**一切皆折叠，一切皆光。**

## 一、灵感映射（词对 → 语言特性）

| 词对 | 落地特性 |

| 齿轮 · 纯度 | **能力式效果系统**：效应不是隐式魔法，而是像齿轮一样被"装配"进程序 |

## 二、六条设计原则

1. **默认安全**：无 `null`、无未声明异常、无隐式可变。程序员想危险的事必须写下齿轮的名字。
2. **效应可见且可组合**：`with gear { Net, Clock } =>` 明示所需能力，效果多态 `'e` 让通用库自然写。
3. **编译器承担举证责任**：总性、穷尽性、资源纪律由类型检查器与求解器保证，而非文档约定。
4. **描述性优先**：错误信息用"灯塔图"呈现——告诉你光被谁折射了、在哪一层可以接住。
5. **极简内核，厚极光库**：语言核心 < 6 条产生式；一切标准库可被用户库替代。
6. **可嵌入**：核心同时是库与运行时（迷你求值器 `spark`），能嵌进宿主，也能当教学语言。

## 三、语法骨架（示例性节选）

```
// 注释 //
let answer : Int = 42                     // 显式类型标注（必需，单态）
let add = \x y => x + y                   // lambda：默认柯里化
fn area (s : Shape) -> Float = ...        // 多参糖，展开为柯里化

type Color  = Red | Green | Blue of Int   // 剪纸：代数类型
type Point  = { x : Float, y : Float }    // 结构化记录（行多态）

match s                                     // 海星：穷尽匹配
  case Red         => 0.0
  case Green       => 1.0
  case Blue n      => n * 1.0
  case _           => beacon Unreachable   // 必须声明或写全

let Circle r = s else beacon NotCircle    // let-else 绑定

p { x = 3.0, ...p }                       // 记录更新（不可变）
xs |> map inc |> filter even              // 树液：管道
a ∘ b ; f ∘̅ g                            // 水母：正/反组合
n = x.field?.orElse 0                     // 珍珠：安全取值

lazy fib = \n => if n < 2 then n else fib (n-1) + fib (n-2)   // 苔藓：自动记忆化
strict budget = costOf x                  // 明确严格

with gear { Clock, Net } =>               // 齿轮：能力装配
  do t <- now ; fetch url

rescue r = case r of                      // 灯塔：接住折射的光
  case Ok v  => v
  case Err e => log.warn e

ch : Chan Str = hive.channel 64            // 蜂巢
spawn worker ~budget 0.25                 // 沙漏：成本预算
n <- recv ch ; send ch "done"
```

## 四、类型系统

- **三种类型的统一代数**：`Sum`（`A | B`）、`Product`（`{...}` / 元组）、`Function`（柯里化箭头）。无名义类型、没有空指针类型。
- **藤蔓结构化子类型**：记录支持行多态，`{ x : Float, ...r }` 可传给需要 `{ x : Float }` 的函数；方法解析沿结构"攀援"。
- **类型即程序**：类型语言是完整的小代数语言，支持条件、量化、模式匹配（可证明性质进入类型）。
- **区域多态**：`region 'r`：区域内的值逃逸检查；`'r` 不出现于结果类型则可栈/区域分配。
- **线性类型**：`move T`（用后即焚）、`borrow T`（只读借用）、共享 `&T`（引用计数）。编译器自动插入 `move`/`borrow`，仅在需要时用 `dup` 显式复制。

## 五、效应系统：齿轮模型

- 效应是**行（row）**：`'e ::= Net | Clock | Log | Hive | Io | ( ... )`。
- 函数签名携带效应行：`fn get url -> Str ~beacon Net, Io`。
- 调用者要么**装配齿轮**（`with gear {...}`），要么在 `rescue` 中**显式接住**（错误折射），二者皆不可逃逸到无记录的纯上下文。
- 无 `unsafe` 块：沙箱由*能力白名单*实现——只把声明过的齿轮交给新模块。

## 六、惰性、记忆化与折叠

- 默认 **call-by-need**；`lazy` 绑定首次求值后自动打补丁（Pearl 式 blackhole 防死循环）。
- `strict` 用于性能热点与资源记账。
- `fold` 是唯一遍历原语：`fold xs (acc) (acc, x) => ...`；`List / Stream / Tree / Map / Chan` 都折叠成同一种形态（纸鹤的一次折叠）。

## 七、并发：蜂巢与沙漏

- 唯一共享机制是**通道**（typed channel），actor = 拥有私有状态 + 一个输入通道的 hive 单元。
- 调度器是**确定性协作式**：并行度默认 = CPU 数，但每段任务带 `~budget` 成本提示；同预算内的顺序可复现（时区·确定性），保证可调试与可复算。
- `spawn` 返回 `Task[T]`，`hive.join`/`hive.take` 汇合；异常经 `rescue` 变成值，蜂巢不会整体崩塌。

## 八、错误处理：无异常的灯塔

- 函数不"抛"，只"折射"：`beacon` 关键字标注所有可能折射出去的错误。
- 编译器做**折射检查**：任何可能折射的调用必须处在 `rescue` 或 `beacon` 声明的作用域内，否则编译失败。
- 好处：错误被静态看见、可被类型化、可跨模块组合，诊断信息给出"光的路径图"。

## 九、宏与编译期

- `spore { ... }` 是卫生准引号：`!mac` 展开在**编译期求值**（可读文件、跑纯代码、生成表）。
- 宏卫生由"种子"保证：用户标识符永不被捕获（种子·卫生）。
- `grow`（递归构造）与 `bloom`（推导式）是内建可引号原语，因此模式匹配、单子式宏都能写。

## 十、完整示例：并发词频统计

```lumen
// 词频：递归 + 记录 + 灯塔 + 蜂巢 + 沙漏
type Freq = { counts : Map Str Int, total : Int }

blank : Freq = { counts = empty, total = 0 }

bump : Freq -> Str -> Freq
bump f w =
  let n = f.counts[w]?.orElse 0
  { f | counts = f.counts.set w (n + 1), total = f.total + 1 }

fn wordsOf (line : Str) : List Str =
  bloom (line |> split /\W+/) (w | w ≠ "") => w |> lower

out : Gear { Log }
in  : Gear { Io }
main : Io Unit
main =
  let chan : Chan Str = hive.channel 256
  let readers = spawn (drain chan) ~budget 0.3
  with hive.parallel 4 do
    for line <- stdin.lines do        // Io 齿轮在此装配
      send chan line
    close chan
    hive.join readers
    let f = fold (wordsOf "..." |> id) blank bump   // 演示真实路径见下
    log.info "字表规模" (f.counts.size) f.total
  where
    // 实际统计走极光库的水母组合子
    stat = compose fold blank bump ∘ wordsOf ∘ concat
    f = stat (drainOf chan)
```

（可读性优先：语法糖被定义为宏，因此 `.set / .get / ∘ / |> / bloom` 全是库函数，不是内建特权——这是"蘑菇·编译期求值"的直接体现。）

## 十一、工具链

- **lumc**：分阶段——解析（布局）→ 卫生展开宏 → 类型/效应/区域求解（约束 + SMT 决策过程）→ 中间表示（"琥珀"字节码，32 寄存器栈机）→ AOT/JIT/WASM 后端。
- **lur**：极小运行时，8 个内建（值、闭包、通道、任务、灯塔、齿轮表、区域、GC），可独立嵌入。
- **spark**：库内迷你解释器，让"解释 Lumen 的 Lumen 程序"只需几十行——教学与自举验证用。
- **Aurora**：标准库，按域分舱（`aurora.text / .list / .net / .hive / .math`），全部以 Lumen 编写，可整体替换。

## 十二、定位与取舍

| 维度 | Lumen 取向 |
|---|---|
| 惰性 | 默认 call-by-need（苔藓） |
| 效应 | 能力行 + 无异常灯塔（齿轮/灯塔） |
| 并发 | 通道 + 预算确定性（蜂巢/沙漏） |
| 类型 | 代数 + 结构化子类型 + 线性/区域（珊瑚/藤蔓/磁铁） |

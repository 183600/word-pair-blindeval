# CLI 工具 Idea：`devlog` —— 开发者工作日志自动生成器

## 核心概念
一个命令行工具，自动从你的开发活动（git commits、分支切换、编辑的文件）中生成每日/每周工作日志和周报。

## 解决的痛点
- 开发者经常忘记记录自己做了什么，写周报/日报很痛苦
- 自由职业者需要给客户汇报工作内容和工时
- 准备绩效评估、面试时需要回顾自己的贡献

## 核心功能

```bash
devlog today          # 生成今天的工作摘要
devlog week           # 生成本周周报
devlog report --from 2024-01-01 --to 2024-03-31  # 自定义时间段
devlog init           # 初始化配置
```

## 实现思路（MVP）
1. **数据源**：扫描指定目录下所有 git 仓库的 commit 历史（按作者邮箱过滤）
2. **智能分组**：按项目、按类型（feat/fix/docs）归类 commits
3. **可选增强**：接入 LLM API，把零散的 commit messages 改写成通顺的工作总结
4. **输出格式**：Markdown / 纯文本，方便粘贴到任何地方

## 为什么适合独立开发者
- ✅ **技术门槛低**：核心是调用 `git log` + 文本处理，单文件脚本就能起步
- ✅ **自己就是用户**：dogfooding，需求理解深刻
- ✅ **可渐进增强**：从本地脚本 → 支持多数据源（GitHub API、Jira）→ LLM 润色
- ✅ **有变现空间**：基础功能免费开源，Pro 版提供 AI 总结、团队聚合、多格式导出
- ✅ **社区传播性好**：开发者工具容易在 HN、V2EX、掘金获得关注

## 差异化方向
- 支持中文输出（现有英文工具如 `standup` 类工具对中文支持差）
- 隐私优先：纯本地运行，数据不出本机
- 与主流 AI 编辑器/工具链集成
